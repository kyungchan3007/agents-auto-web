## 성능 · 접근성 (지킬 것)
| 규칙 | 방법 |
| --- | --- |
| 3D 없이도 내용은 다 보임 | 숫자 · 신호는 항상 글자로도 표시 |
| 화면에 보일 때만 그림 | 보이지 않는 3D는 멈춤 |
| 휴대폰 | 3D를 단순화하거나 정지 그림으로 |
| "움직임 줄이기" 설정 | 애니메이션 멈춤 (`prefers-reduced-motion`) |
| 키보드 · 스크린 리더 | Base UI 부품 사용 · 3D 캔버스에는 대체 설명 |
| 대비 | 글자 · 배경 대비는 토큰 만들 때 측정해서 기록 |
