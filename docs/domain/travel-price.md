# 여행지 물가 비교

## 용어
| 용어 | 뜻 |
| --- | --- |
| 물가 수준 | 나라별 물가 (미국 = 1, 연 단위) = 세계은행 가계 소비 PPP `PA.NUS.PRVT.PP` ÷ 시장 환율 `PA.NUS.FCRF` |
| 한국 대비 | 같은 연도의 (그 나라 물가 수준 ÷ 한국 물가 수준) · 1.2 = 한국보다 20% 비쌉니다 |
| 체감 물가 | 물가 수준 × 오늘 환율을 합친 값 (가정) |

## 출처 (2026-10-28 직접 호출로 확인)
- 처음 제안한 `PA.NUS.PPPC.RF`(GDP 물가 수준 비율)는 **WDI Database Archives 로 옮겨져 API 에서 안 나옴**
- 대신 가계 소비 PPP ÷ 시장 환율 — 여행자 체감에 더 가까움 (가정) · 마지막 갱신 2026-10-08 · 2025년까지
- 세계은행 안내: 물가 수준 비율은 나라 순위를 정밀하게 매기는 데 쓰지 말 것 → 화면은 "싼 편 · 비싼 편" 정도로

## 화면 규칙 (작업 0068 · 가정)
- 묶음: 한국 대비 0.9 미만 싼 편 · 1.1 초과 비싼 편 · 그 사이 비슷 (`@hav/shared/travel` BAND_EDGE)
- 나라 목록은 한국인 여행이 많은 나라 고정 표 (`TRAVEL_COUNTRIES`) · 표에 있어도 자료가 없으면 빼고 "자료가 없어 뺀 나라" 로 적음 (대만은 세계은행 자료에 없음)
- 체감 물가(물가 × 오늘 환율) 숫자는 만들지 않음 — 오늘 통화 신호를 옆에 글자로만

## 월간 지표 채우기 (작업 0171)
- KOSIS 여행 품목 · ECOS 수입물가 같은 월간 지표는 비었거나 발표된 달보다 오래되면 평일 12:00 회차에서도 채움 (KOSIS 5일 · ECOS 17일 이후 기대 달 = 지난달 · 자료당 하루 최신 1행만 읽음 · 매달 1일 회차는 그대로)

## 한국인이 많이 가는 나라 (작업 0360 · 확인한 날 2026-11-25)
- 출처: 한국관광공사 한국관광 데이터랩 "2025년 12월 기준 국민 해외관광객 주요 목적지별 통계"(202512.xlsx, 2026-02-05 게시) https://datalab.visitkorea.or.kr/site/portal/ex/bbs/View.do?cbIdx=1127&bcIdx=310224
- 자료 성격: 2006년 출국카드 폐지 뒤 나라별 도착 집계가 없어, 각 나라 관광 당국이 발표한 한국인 입국 수를 모은 표 (출국한 사람 수가 아니라 도착한 사람 수 · 법무부 출입국 통계에는 목적지별 표가 없어 쓰지 않음)
- 기준: 2025년 1월 ~ 12월 합계 · 12개월이 모두 있는 나라만 순위에 넣음 · 파일에서 월별 값을 직접 합산
