## 허점
- 시트로 고르면 예산이 0 이거나 인트로 값(이어 씀) — 탑승권 요약의 환율 · 판정은 그대로 나오고 예산 줄만 숨김.
- 인트로 창문 전환 사진은 e2e 로 보지 못함(인트로가 config 로 꺼져 있고 3D 장면이 있어 GPU 가 필요) — 코드는 `view.photo` 한 줄이며 사진 이름 규칙은 단위 테스트가 확인. 미리보기에서 실제 Chrome 으로 확인 필요.
- 넓은 화면의 시트는 가운데 대화 상자로 보임(휴대폰만 아래에서 올라옴) — 시안은 휴대폰 기준.
- 통화 · 서버 HTML · 저장 방식은 바꾸지 않음. 사진이 없는 나라(두바이 등 19개 밖)는 지금 사진.
