> ## 바꿀 것
> 1. **블프 기간(~2026-12-01 17:00 KST, 기존 기간 상수 그대로)**: 첫 페이지 hero 를 캐러셀 두 장으로.
>    - 1장 블랙프라이데이(처음 열리면 이 장) · 2장 여행 타이밍(기본 울트라마린 탑승권).
>    - 기간이 끝나면 기본 hero 한 장만, 캐러셀 버튼 없음 (지금 기간 전환 방식 그대로 · 경계 테스트 유지).
>    - 12월 1일 뒤 블프 코드 삭제는 따로 (이번 범위 아님).
> 2. **넘김**
>    - 자동 넘김: 블프 9초 · 기본 7초. 바뀔 때 글 · 그림만 0.35초 흐려졌다 나타남 (배경색은 0.5초 바뀜).
>    - 버튼: hero 아래 가운데 알약 두 개 "블랙프라이데이" · "여행 타이밍"(고른 장은 노란 점 · 아래 노란 줄이 남은 시간만큼 참). 900px 이상은 양옆 ‹ › 도. 휴대폰은 옆으로 밀기(50px 이상).
>    - 899px 이하에서는 버튼을 그림 아래 흐름 안에 둔다 (겹치지 않게).
>    - 마우스를 hero 위에 올리면 잠시 멈춤 · 떼면 남은 시간부터.
>    - **입력하면 자동 넘김 취소**: hero 안 입력칸 · 고르기 칸(input · select)에 초점이 가거나 값을 넣으면 자동 넘김을 아예 끈다(다시 켜지지 않음 · 노란 줄도 사라짐). 버튼 · 밀기로 넘기는 것은 됨.
>    - 움직임 줄이기 설정이면 자동 넘김 없음.
>    - 접근성: tablist / tab, aria-selected, 보이지 않는 장은 inert(초점 · 화면 읽기에서 빠짐). h1 은 보이는 장 하나만 읽히게.
> 3. **두 장 높이 같게** (넘길 때 위아래로 움직이지 않음)
>    - CSS 로: 두 장을 같은 grid 칸에 겹쳐 두고(grid-area 1/1) 안 보이는 장은 visibility:hidden + inert. 그러면 hero 높이 = 긴 장. **JS 로 높이를 재지 않는다** — 시안에서 JS 로 보이는 hero 의 class 를 바꿔 재다가 영수증이 한 줄 찍힐 때마다 입력칸이 다시 그려지는 문제가 있었음.
>    - 블프 입력 · 영수증 카운트업 · 기본 hero 칩 · 입력은 서로 상태를 나누지 않는다 (영수증이 움직여도 입력칸이 다시 그려지면 안 됨).
> 4. **블프 입력칸은 숫자만**
>    - 0-9 외 글자(문자 · 기호 · 한글 · 소수점 · 쉼표 · - · $)는 들어가지 않음. 붙여넣기 · 한글 조합 입력도 같음. inputmode="numeric" · pattern="[0-9]*".
>    - 예: "12a3"→"123", "$250"→"250", "1,000"→"1000", "가나12"→"12", 붙여넣기 "ab99cd"→"99". (소수점도 막으므로 "1.5"→"15")
>    - 입력 처리는 순수 함수(lib)로 · tsx 에 로직 없음(코드 구조 기준).
> 5. **블프 장 반응형** — 기본 장과 같은 기준
>    - 1200 이상: 글 왼쪽 · 영수증 오른쪽.
>    - 900~1199: 나란히 · 글 최대 50vw · 영수증 30vw · 뒤 영수증 한 장 숨김.
>    - 899 이하: 영수증을 글 아래 가운데(최대 300px).
>    - 지금 운영은 720~899px 에서 글과 영수증이 겹침(사용자 캡처). 이것도 고침.
>    - 기본 장: 899 이하에서 탑승권을 26px 내려 위쪽 가격표가 도시 칩에 닿지 않게.
