# PRD: 첫 페이지 hero 캐러셀

## 목표
- 블프 기간(~2026-12-01 17:00 KST)에 첫 페이지 hero 를 두 장 캐러셀로: 1장 블랙프라이데이(처음 열리면 이 장) · 2장 여행 타이밍(기본 울트라마린 탑승권). 기간 뒤엔 기본 hero 한 장 · 캐러셀 버튼 없음.
- 넘길 때 hero 높이가 바뀌지 않음(어지럽지 않게).
- 사용자가 입력하면 자동 넘김을 끔.
- 블프 입력칸은 숫자만.
- 블프 장 반응형(지금 720~899px 겹침) 고침.

## 요구 (작업서 번호)
- R1 기간: 기존 BF_END · 전환 방식 그대로 · 경계 테스트 유지 · 블프 코드 삭제는 범위 밖.
- R2 넘김: 자동 블프 9초 · 기본 7초 · 글 · 그림 0.35초 흐려졌다 나타남 · 배경색 0.5초. 아래 가운데 알약 "블랙프라이데이" · "여행 타이밍"(고른 장 노란 점 · 노란 줄이 남은 시간만큼) · 900px 이상 양옆 ‹ › · 휴대폰 옆으로 밀기 50px 이상 · 899 이하 버튼은 그림 아래 흐름 안 · 마우스 올리면 멈춤(떼면 남은 시간부터) · hero 안 input · select 에 초점 또는 값 입력 → 자동 넘김 영구 끔(노란 줄 사라짐 · 버튼 · 밀기는 됨) · 움직임 줄이기면 자동 없음 · tablist/tab · aria-selected · 안 보이는 장 inert · h1 은 보이는 장 하나만 읽힘.
- R3 높이: 두 장을 같은 grid 칸에 겹침(grid-area 1/1) · 안 보이는 장 visibility:hidden + inert · JS 로 높이 재지 않음 · 두 hero 의 상태를 나누지 않음(영수증이 움직여도 입력칸이 다시 그려지지 않음).
- R4 숫자만: 0-9 외 글자 막음(붙여넣기 · 한글 조합 포함) · inputmode=numeric · pattern=[0-9]* · 예 "12a3"→"123" · "$250"→"250" · "1,000"→"1000" · "가나12"→"12" · "ab99cd"→"99" · "1.5"→"15" · 순수 함수(lib).
- R5 반응형: 블프 장 1200 이상 글 왼쪽 · 영수증 오른쪽 / 900~1199 나란히 · 글 최대 50vw · 영수증 30vw · 뒤 영수증 한 장 숨김 / 899 이하 영수증 글 아래 가운데(최대 300px). 기본 장 899 이하 탑승권 26px 아래로.

## 그대로
- 두 hero 의 문구 · 그림 · 영수증 · 탑승권 모션 · 계산 규칙.
