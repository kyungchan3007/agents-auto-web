# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 화면 파일 12개가 상태 · 이벤트 처리 · 계산을 JSX 와 한 파일에 둠 (예: calc-form · currency-list · budget-planner)
- 커스텀 훅은 2개뿐이고, `useFavorites` 는 순수 함수 파일에 섞여 있음
- home.tsx 는 237줄에 자료 가공과 화면 다섯 칸이 함께 있음
- 같은 코드 중복: 주소 값 읽기 2곳 · 신호 색 3곳
- 기능 폴더 직접 참조 1건 (about → import-calc) · 경계 규칙은 "(예정)" 으로 강제되지 않음

## 목표
- 화면(`.tsx`)은 그리기만 · 상태와 이벤트는 커스텀 훅(`use-*.ts`) · 계산은 순수 함수(`*.ts`, 테스트 있음)
- 규칙을 테스트로 강제해 다시 섞이지 않게 함

## 비목표
- 화면 · 문구 · 동작 변경 없음
- 백엔드 수정 (이번에는 점검 결과만 보고)
- `packages/ui` 3D 컴포넌트 내부, 개발용 `/design` 페이지

## 완료 기준
- [ ] `apps/web/src/features` · `shared` 의 `.tsx` 에서 React 상태 훅을 직접 쓰지 않음 (테스트)
- [ ] 기능 폴더끼리 직접 참조 없음 (테스트)
- [ ] 분리한 계산에 단위 테스트
- [ ] 게이트 Full (typecheck · lint · test · build · e2e) 통과
