## 허점 (구현 뒤 · builder)
- 저장된 칩이 있으면 서버 첫 그림은 기본 네 통화라 칩 줄이 잠깐 바뀌어 보이던 것을, currencies layout 의 작은 스크립트(<html data-recent-chips>)와 CSS 로 저장이 있는 사람만 하이드레이션 전까지 칩 줄을 숨겨 막음(높이는 그대로 · 밀림 움직임 없음) — 저장이 없거나 JS 가 꺼져 있으면 바로 기본 칩
- 목록에서 고르면 날아가는 국기의 출발은 맨 앞에 새로 붙은 칩 자리 — 칩이 막 미끄러져 들어오는 중이라 자리가 조금 움직일 수 있음
- 글자판은 숫자 칸만 굴러감: 쉼표 · '원' 칸은 그대로 · 값이 "—"(비었거나 틀린 입력)일 때는 굴러가지 않고 바로 바뀜
- 휴대폰에서 칩 줄 · 상자가 좁으면 칩이 옆으로 넘쳐 스크롤됨(지금 칩 줄과 같음) · 실제 휴대폰 · 사파리 움직임은 직접 못 봄
- 전환 중 다시 다른 통화를 빠르게 누르면 마지막 것으로 이어 감(직전 값은 마지막 페이지가 적은 값)
