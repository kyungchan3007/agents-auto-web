# PRD — 무엇을 · 왜

> 요청 원문: [request.md](request.md) "### 3. 통화 상세"

## 문제
- 통화 상세에서 다른 통화를 고르면 지금은 화면이 그냥 바뀐다. 사용자가 고른 모션 7번(통화 바꾸기 전환) · 4번(글자판 굴러가기)과, 사용자가 덧붙인 "고르면 위로 올라감" · "고른 통화 칩 5개 + 더보기"를 더해야 한다.

## 목표
- **7번 전환:** 통화를 고르면 차례로 — 고른 칩의 국기가 포물선으로 제목 옆 국기 자리로 날아감 → 이름 · 제목 · 신호 글 바뀜 → 큰 환율과 1년 최저 · 최고 · 평균 카운트업 → 막대 위 비행기가 새 자리로(왼쪽으로 가면 기수를 돌림) → "실제로 바꿀 때" 글자판이 4번처럼 굴러가고 입력 · 빠른 금액이 그 통화로 → 1년 그래프 · "이 통화 쓰는 나라 물가 보기" 링크도 그 통화로.
- **위로 올라감:** 아래 "둘러보기" 목록이나 칩에서 고르면 화면이 환율 자리까지 부드럽게 올라간 뒤 전환 시작. 목록의 고른 표시(테두리)도 옮겨 감.
- **고른 통화 칩:** 고른 통화는 칩 줄 맨 앞에 붙고 나머지는 한 칸씩 미끄러지며 밀림(이미 있으면 맨 앞으로 · 6번째로 밀린 칩은 오른쪽으로 빠지며 사라짐) · 줄에는 5개까지 + "더보기 +N" · 더보기는 칩 줄 아래 **떠 있는** 상자(옆 검색칸 · 아래 내용 안 밀림) · 상자에 고른 칩 모두, 한 쪽 5개 · "‹ 1 / 2 ›" 옆으로 미끄러지며 넘김 · 상자에서 고르면 닫히고 전환. 처음 칩 줄은 지금 운영 그대로.
- 지금 화면에서 빼는 것 없음. 숫자는 받은 자료만.

## 비목표
- 시안의 "시안에는 4개 통화 값만" 안내 띠(시안 전용)는 넣지 않는다 — 실제 구현은 모든 통화.

## 애매한 곳
- 고른 목록을 다음 방문까지 남김: 기존 즐겨찾기(use-favorites)와 같은 브라우저 저장 방식(localStorage · 같은 탭 · 다른 탭 반영)으로 새 키에 저장 (lead 판단 · 브리프 "기존 방식이 있으면 따름")
- 움직임 줄이기면 스크롤 · 전환 · 칩 밀림 없이 바로 최종 (확인됨: 브리프 공통 원칙)
