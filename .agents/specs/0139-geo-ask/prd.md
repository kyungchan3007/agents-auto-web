# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 지금 GEO 측정은 AI 봇이 찾아오기를 기다리는 방식이다. 기록 시작(2026-11-05) 뒤 AI 봇 · AI 서비스 유입이 0이라 "측정이 안 되는" 것처럼 보인다.
- AI 답변이 이 사이트를 인용하는지는 지금 어떤 수치로도 알 수 없다.

## 목표
- 정해 둔 질문을 AI 검색(웹 검색 API)에 매일 직접 보내, 답의 출처에 tripfx.pages.dev 가 나왔는지 기록한다.
- 측정 페이지(/geo)에 "AI 답변 인용" 칸을 두고, 서비스별 최근 측정일의 인용 수 · 검색 결과 등장 수 · 질문 수와 인용된 질문을 보여 준다.

## 비목표
- 답변 본문 저장 · 공개 (출처 주소 판정 결과만 저장)
- 순위 · 경쟁 사이트 비교
- 네이버 · 구글 AI 개요 측정 (공개 API 없음)

## 애매한 곳
- 질문: 2026-11-05 기준선과 같은 24개 (가정 · 비교가 되도록)
- 서비스: Claude(Anthropic) · ChatGPT(OpenAI) · Perplexity. 키가 있는 서비스만 측정하고, 없으면 "측정 안 함"으로 둔다 (가정 · 키는 사람이 GitHub 비밀값으로 등록)
- 주기: 매일 한국 05:00 (가정 · 사용자가 "매일" 제안에 "추가해")
- 모델: Claude 는 claude-opus-5-5 · effort low (가정 · 비용은 사용자에게 알림). OpenAI · Perplexity 모델은 환경 변수로 바꿀 수 있게 기본값만 둔다 (가정)
- "인용" = 답 본문의 출처(인용 표시)에 tripfx 주소가 있음 · "검색 결과" = 검색 도구가 받은 결과 목록에 있음 (가정)
