## 허점
- 미리보기 · API 배포 전에는 새 필드가 없어 봇 · 유입 · 답변이 "아직 없음" — API 머지 · 배포 뒤 실제 숫자가 보임 (운영 /geo 응답에 daily 가 오는지 배포 뒤 확인 필요).
- 응답 크기: answerDays 는 30일 × 서비스 3 × 질문 24 = 최대 약 2천 줄(질문 글자 포함) — 측정일이 쌓이면 커짐. 필요하면 질문 번호로 줄이기.
- 질문별 표는 휴대폰에서 가로 스크롤(표 안) — 페이지 가로 넘침은 없음.
- 후 기간이 짧아(2일) 전후 차이는 참고용 · 같은 날 AI 봇 방문이 몰리는 일 등은 구분하지 않음.
