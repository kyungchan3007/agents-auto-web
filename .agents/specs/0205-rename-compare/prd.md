# PRD — 무엇을 · 왜

> 요청: [request.md](request.md) · 이슈 #243

## 문제
- 사이트 이름 · 주소를 2026-11-17 에 Tripfx(tripfx.pages.dev) → Flapfx(flapfx.com)로 바꿨는데, /geo 는 누적 합계만 보여 바꾸기 전 · 후를 비교할 수 없다.
- 봇 방문은 누적(GPTBot 89 등)만 · AI 답변 측정은 날짜별 기록뿐 · 검색 노출은 옛 속성만.

## 요구사항
- P1 **기준일 한 곳**: `2026-11-17`(이름 · 주소 바꿈)을 공용 상수 하나로(`@hav/shared` 의 geo 계약 옆). 화면에 "이름 바꾼 날 2026-11-17 (Tripfx → Flapfx)" 로 표시.
- P2 **/geo 맨 위 "이름 바꾼 날 전후 비교"** 구간 (지금 내용은 그 아래 그대로):
  - 봇 방문: 봇별로 바꾸기 전(첫 기록 ~ 11-16) · 후(11-17 ~ 마지막 날) **하루 평균**을 나란히 + 날짜별 막대(작은 막대 그래프 · 기준일에 세로선).
    - 하루 평균의 분모는 그 기간의 달력 날짜 수(첫 기록일 ~ 11-16 / 11-17 ~ 오늘 한국 날짜) — 방문이 0인 날도 날짜에 넣음. 분모를 화면에 적음("16일 · 2일").
  - AI 서비스 유입(referral): 전 · 후 합계와 하루 평균 · 없으면 "아직 없음".
  - AI 답변:
    - 일반 질문 16개는 같은 질문(id)끼리 이어 비교 — 바꾸기 전 측정일들 · 후 측정일들의 found · cited 횟수 / 측정 횟수.
    - 브랜드 질문은 이어 비교하지 않고 "Tripfx 시기(2판까지)" / "Flapfx 시기(3판)" 따로 요약.
  - 검색 노출: 옛 속성(tripfx.pages.dev) 숫자 / 새 속성(flapfx.com) — 새 속성은 등록 뒤부터 · 지금은 "아직 없음 (Search Console 새 속성 등록 대기 #214)".
- P3 **API**: `/geo` 응답에 비교용 자료를 더함 — 봇 · 유입의 **날짜별** 집계(일 · 이름 · 횟수)와 답변의 날짜별 질문 결과. 기존 필드는 그대로(하위 호환). 지난 기록(D1 · data/geo-answers/*.json)은 고치지 않음.
- P4 숫자는 실제 값만 · 자료 없는 칸은 "아직 없음" · 지어내지 않음. 기간이 짧다(후 2일)는 것을 화면에 적음("후 기간이 짧아 비교는 참고용").
- P5 휴대폰 · 데스크톱에서 겹침 · 가로 넘침 없음 · 막대에는 접근 가능한 글(표 또는 aria-label)로 같은 숫자.
