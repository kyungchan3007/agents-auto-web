## 허점
- 사진 고르는 규칙은 `headerPhoto(기본 사진, 나라)` 하나(photo.ts) — 홈 · 여행 물가 · 고른 나라 모두 같은 함수. 고른 나라가 있으면 0201 그대로(고른 나라 사진이 없으면 지금 사진 · 기본 나라 사진으로 돌아가지 않음).
- 홈 기본 나라는 안내판과 같은 계산(cheapestDestination) · 지금 파리 → country-eur(에펠탑). 도착지가 없거나 나라 코드 없으면 지금 사진. 빌드 때 정해지는 값이라 e2e 는 서버 HTML 안내판 글에서 기대 사진을 구함.
- 덮개: 휴대폰 홈만(`clearTop`) — 글자 자리(아래 ~ 60%)는 90% · 위쪽은 90% 지점까지 걷어 맨 위 10% 투명. 첫 구현(45% 까지)은 작은 제목(초록) 대비가 2.2:1 로 떨어져 e2e 가 잡았고, 60%/90% 로 고쳐 글자 3군데 하위 1% 대비 ≥ 4.5 통과. 다른 화면의 light 덮개는 그대로.
- 노란 표시줄: 글자 옆 여백만큼 넓어 보여(넓은 화면 왼쪽 5px · 오른쪽 3px 더 나감) 띠를 양쪽 0.05em 안쪽으로 줄임 → ±2px 안. 공통 부품(emph)이라 모든 light 강조에 적용 — 여행 물가 · 홈 · 비행 · 통화 캡처 확인(.tmp/h9-*.png · 어색한 곳 없음).
- 빌드 2번(덮개 대비를 e2e 로 잡아 고친 뒤 다시 빌드) — 요청은 한 번까지.
