- 막대 길이 비례: 어드민 막대는 화면에 들어올 때 채워지는 움직임(작업 0303)이라 화면 밖에서는 그려진 폭이 0 → 정한 폭(style width %)으로 비교
- 빈 상태 글: 어드민은 마침표 없음("아직 기록이 없습니다") → 글 앞부분으로 확인
- 줄 겹침: 봇 카드가 세 칸 격자로 나란히 놓여 다른 카드 줄끼리 위아래를 비교함 → 카드 안 줄끼리 비교
