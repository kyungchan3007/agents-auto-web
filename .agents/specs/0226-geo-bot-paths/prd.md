# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- /geo "AI 봇이 읽은 페이지"는 봇을 모두 합친 경로별 횟수라, 어느 봇이 어느 페이지를 읽었는지 알 수 없다. #157 조사에서 ClaudeBot · Googlebot 방문이 크게 늘었는데 무엇을 읽었는지 확인하지 못했다.

## 목표
- /geo 응답에 봇별 읽은 경로 집계를 선택 필드로 더하고(하위 호환), /geo 화면에 봇마다 어떤 경로를 몇 번 읽었는지 보여 준다.
- 봇: 방문 기록에 남는 모든 봇(학습 · 검색 · 사용자 요청 봇과 Googlebot · bingbot 같은 검색 엔진). 사람 유입(referral) · 운영 확인(test)은 뺀다.

## 비목표
- 스키마 · 마이그레이션 변경 없음(방문 기록 행에 이미 day · kind · name · path · hits 가 함께 있음 — 확인됨)
- 새 D1 쿼리 없음(지금 읽는 30일 창의 같은 행을 다시 묶기만)
- 기존 "AI 봇이 읽은 페이지"(합계 · 검색 엔진 제외) 카드의 뜻은 바꾸지 않음

## 애매한 곳
- 화면 배치: 시안 B 의 카드 · 가로 막대 문법 그대로, 봇마다 작은 막대 묶음(가정 · 시안에 이 카드는 없음 → 기존 카드와 같은 모양)
- 봇마다 보여 줄 경로 수: 많이 읽은 순으로 상위 5개 + 나머지는 "그 밖 N곳 · M회"(가정)
