## 흔들림 원인과 고친 것 (test · 2026-11-20)
- 공통 원인: 서버가 그린 그림 · 하이드레이션 전 · 첫 배치 전에 값을 한 번 읽음. 로컬(빠른 기기)에서는 --workers=4 --repeat-each=5 로도, CPU 부하를 걸어도 재현되지 않았고, 크롬 개발자 도구 프로토콜로 CPU 를 6배 느리게 한 임시 복사본 spec 에서 CI 와 같은 증상이 그대로 재현됨(다섯 대상 모두 · 총 33건 실패)
- 고친 것 — 고정 대기 대신 신호를 기다림 · 검사 내용 · timeout · retries 는 그대로 · 공용 도움 `hydrated()`(e2e/helpers.ts: React 가 요소를 이어받을 때까지 + 두 프레임)를 더함
  - currency-chart.spec.ts:146 '한 번만 — 위로 올라갔다 다시 와도 다시 그리지 않음': 서버 첫 그림이 이미 data-state="done"(최종 모양)이라 하이드레이션 전에 '끝남'을 읽고 지나가면, 이어받은 뒤 그래프가 처음 모양으로 돌아가 다시 그려짐(설계상 정상: 내용 먼저 · 움직임 나중). → 이어받은 뒤(hydrated)에 스크롤하고 '끝남'을 기다림
  - detail-design.spec.ts:90 '세 카드는 같은 틀': 첫 그림이 끝나기 전 카드마다 스타일이 달라 6칸이 모두 어긋나 읽힘 → 같은 틀이 될 때까지 다시 읽는 expect.poll (끝내 다르면 시간 초과로 실패) · 제목 색 · 구분 점 색도 같은 방식
  - prices-route.spec.ts:94 '정거장 사이 스크롤 길이': 정거장 카드가 하이드레이션 뒤에 그려져 그 전에 세면 n = 0 → (n - 1) = -1 로 나눠 -216 · -180(= -6 × 36 · -6 × 30)이 나왔음 → 이어받고 정거장이 그려진 뒤에 세고, 구역 높이도 최종이 될 때까지 다시 읽음 · 고정 150ms 대기는 판이 메뉴 띠 아래에 붙을 때까지 다시 읽는 poll 로
  - prices-route.spec.ts:80 '정거장 = 아래 목록의 맨 위 나라들': 목록 줄이 최종 배치 전에는 innerText 첫 줄에 이름 · 물가 · 알약이 붙어('인도 국기인도물가 37 (한국 100)환율 없음') 읽힘 → 첫 줄이 이름뿐인 최종 모양이 될 때까지 기다리는 listPins (같은 도움을 쓰는 같은 파일의 다른 테스트도 함께 안정됨)
  - pages.spec.ts:342 '나라 접기 버튼 모양': 단추가 보인 직후 계산된 스타일이 비어 NaN → 다시 읽는 검사(expect.poll · toHaveCSS)로 · 이어받기 전에 누르면 눌림이 무시될 수 있어 누르기 전에 hydrated
- 확인(0239 규칙 · 로컬은 이 spec 네 파일만)
  - 임시 복사본(CPU 6배 느리게 · --workers=4 · --repeat-each=3~4 · --retries=0): 고치기 전 33건 실패(다섯 대상 모두 포함) → 고친 뒤 다섯 대상 0건(두 화면 · 3 ~ 4번 반복) — 복사본 spec 은 확인 뒤 지움(저장소에 없음)
