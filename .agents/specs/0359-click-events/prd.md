# PRD: 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 이탈 줄이기 묶음에서 새로 넣은 버튼 · 링크를 실제로 누르는지 볼 숫자가 없다. 어드민에는 페이지별 머무름(#404)만 있다.

## 목표
- 운영 사이트(GA4 가 켜지는 운영 주소에서만)가 새 버튼 · 링크를 누를 때 버튼마다 다른 이름의 GA4 이벤트를 보낸다.
- GA4 수집이 최근 28일 이벤트별 횟수 · 누른 사람 수를 받아 저장한다.
- 어드민 유입(/traffic) 화면 "페이지별 머무름" 아래 "버튼 클릭" 표: 버튼 이름(한국어) · 있는 페이지 · 최근 28일 클릭 수 · 누른 사람 수 · 하루 평균. 표 위에 보내기 시작한 날, 그 전 날짜는 "기록 전".

## 비목표
- GA4 맞춤 측정기준 등록 · 새 비밀값 · DB 스키마 · 워크플로 변경.

## 애매한 곳
- 하루 평균: 보내기 시작한 날부터 어제까지의 날 수로 나눔(28일이 안 차면 실제 날 수) (가정).
- 작업 종류 ③: 요구마다 기능 테스트.
