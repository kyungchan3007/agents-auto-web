## 무엇을 · 왜
- 시안 10-C: 통화 상세 "실제로 바꿀 때" 카드 아래 빈 자리에 "다른 나라 통화 보기" 버튼 → 누르면 오른쪽 사이드바(휴대폰은 아래 시트)에 둘러보기 표와 같은 자료 · 같은 순서의 통화 목록. 사용자가 정한 모션 A(버튼이 늘어나 사이드바) + 스크롤 1(열린 동안 뒤 화면 잠금).
- 버튼: 0355 의 공통 테두리 부품 규칙을 따름(두 곳 이상 쓰는 버튼은 공통). 양끝 · 모서리 둥글기는 위 카드와 같게, 아래선은 왼쪽 "1년 최저 · 최고" 카드 아래선에 맞춤(사용자 직접 지적).
- 국기: 기본은 목록 앞 네 통화 · 고르면 그 통화 하나 · 아래 줄 "고른 통화 · 일본 엔 100 846.76원". 고른 값은 페이지 안에서만.
- 통화 줄 누르면 사이드바 닫히는 움직임 → 지금처럼 그 통화로 바뀌는 전환.
- 모션 A 는 시안 코드(.tmp/sian-retention/index.html 의 m10- · show() · hide())를 기준으로: 0.7초 · cubic-bezier(.7,0,.25,1) · 버튼 글 0.16초에 사라짐 · 국기가 곡선으로 제 줄로 · 펼쳐진 뒤 줄이 차례로 · 닫을 때 반대 + 버튼 살짝 튐 · 고른 통화가 아래쪽이면 미리 내려 둠. 움직임 줄이기면 바로. 자바스크립트 없으면 둘러보기 링크.
- 스크롤 1: 열린 동안 페이지 스크롤 잠금(스크롤바 자리로 옆 밀림 없음) · 목록 overscroll-behavior contain · 닫으면 원래 위치.
- 접근성: aria-expanded · role=dialog + 이름 · 포커스 안으로 · 닫으면 버튼으로 · Esc · 포커스 가두기.
- 작업 종류 ③(동작 · 사용자 조건): 요구마다 기능 테스트. 움직임의 시작 · 끝 모양은 @design.
