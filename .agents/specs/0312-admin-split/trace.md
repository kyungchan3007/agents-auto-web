## 허점
<!-- 이번 작업에서 드러난 실수·구멍. 같은 허점이 두 번 나오면 하네스(검사·훅·린트)로 막는다 -->
- 소스 경로를 글로 읽는 테스트가 많아(apps/web/src/shared 44개) 폴더를 옮길 때마다 조용히 깨짐 — 화면 모양 검사는 경로 하나가 아니라 기능 폴더 전체를 읽게 바꾸는 편이 덜 깨짐
- 훅(e2e 가드 · 작업 폴더 규칙)은 메인 폴더의 판으로 돎 — 하네스를 고치는 작업에서는 새 규칙이 머지 전까지 적용되지 않아 어드민 e2e 를 로컬에서 못 돌림
- git 에 올리지 않은 새 파일을 git mv 하다 옮기기가 중간에 멈춘 일 — 옮김 도구는 실행 전에 git add 를 먼저
