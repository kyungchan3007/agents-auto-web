지금 열린 이슈 전부다 처리해

(대상 이슈 #117 "GEO 대응" 의 3. 인용하기 좋은 내용 · 5. 측정)
- 사이트 소개 · 판단 기준 페이지 추가
- 통화 상세에 "기준일 · 환율 · 평균 대비 · 판단" 요약 문장 추가
- 차트에만 있는 기간별 변화를 표로도 제공
- 기준일을 `<time>` 태그로 표시
- 페이지 내 환율 출처 표기가 일관된지 확인 · 수정
- 직구 면세 기준의 근거 출처와 확인일 표기
- 수정 전 기준선 측정 (질문 20~30개, 브랜드 · 일반 분리)
- 검색 발동 여부와 인용 주소를 함께 기록
- AI 봇 방문 · AI 서비스 유입을 볼 방법 검토
- 통화 절반에만 3번을 먼저 적용해 나머지와 비교
- 재색인 시간을 고려해 2~4주 뒤 재측정
