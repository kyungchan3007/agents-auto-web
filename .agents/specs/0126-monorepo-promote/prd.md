# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 기능 2개 이상이 쓰는 모듈이 앱 안 `apps/web/src/shared` 에 있음 (국기 · 날짜 · 그래프 · 신선도 안내 · 3D 로더 · 주소 값 읽기 · 신호 색)
- 반복되는 디자인을 화면마다 클래스로 다시 씀 (지역 단추 · 단위 입력 칸 · 자료 없음 칸 · 꼬리말 · 글 링크 · 작은 제목 · 큰 제목 · 숫자 칸)
- 한국 시각 계산이 앱 · API · 패키지 5곳에 흩어져 있고, API 기능 폴더 하나가 다른 기능의 파일을 가져옴

## 목표
- 공통 로직은 `@hav/shared`, 공통 디자인 · 훅은 `@hav/ui`
- 앱 공용 폴더에는 이 사이트 고유 설정만 남기고 테스트로 강제

## 비목표
- 화면 · 문구 · 동작 변경 없음
- 백엔드 역할 분담 수정 (점검 결과만 보고)
- `packages/config` eslint 추가 (보호 파일 · 별도 작업)

## 완료 기준
- [ ] 2개 이상 기능이 쓰는 공통 모듈 · 디자인이 패키지에 있음
- [ ] `apps/web/src/shared` 허용 목록 테스트
- [ ] API 기능 폴더끼리 직접 참조 없음
- [ ] 게이트 Full 통과
