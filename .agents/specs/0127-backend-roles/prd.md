# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 라우트 3곳에 쿼리와 가공이 함께 있어 다른 기능(`store.ts`)과 역할이 다름
- 예외가 나면 Hono 기본 글자 응답이고 로그가 없어, 예약 수집이 왜 실패했는지 Cloudflare 로그로 볼 수 없음 (이슈 #128 조사의 한계)
- `Env` 를 손으로 써서 설정과 어긋나도 모름 · 운영 오류 위치를 소스로 찾을 수 없음
- API · 패키지에 린트가 없고, 끝나기 전에 응답하는 Promise 를 검사하지 않음

## 목표
- 라우트는 입력 · 응답 · 조립만 · 쿼리는 `store.ts` · 계산은 순수 함수
- 예외는 한 가지 JSON 모양 · 로그는 JSON 한 줄 · 비밀값은 로그에 남기지 않음
- 바인딩 타입은 설정에서 생성 · 소스 맵 업로드
- 모든 패키지가 공용 eslint 를 씀

## 비목표
- API 응답 모양 변경 (성공 응답) · 수집 규칙 변경 · DB 스키마 변경
