> ## 시안 (사용자 확인 끝)
> - `.tmp/mock-admin-gate/index.html` — 세 장면: ① 막는 화면(링크 없이 주소만 · 토큰 직접 입력은 접어 둔 예비 수단) ② 첫 진입 안내 창(한 번만) ③ 사용할 수 없는 링크. 어드민 지금 색 · 글꼴(.adm 토큰) 그대로.
>
> ## 흐름
> 1. 지원 링크 `https://admin.flapfx.com/?t=<토큰>` → 어드민 Worker(`apps/admin/worker/index.ts`, run_worker_first)가 토큰 확인 → 맞으면 쿠키 심고 `?t` 를 지운 주소로 303 이동 → ② 안내 창. **리뷰어는 아무것도 입력하지 않음.**
> 2. 쿠키 없이 주소만으로 오면 ① 막는 화면. 접힌 "토큰 직접 입력"은 `POST /login` (같은 확인 · 같은 쿠키).
> 3. 토큰이 틀렸거나 지웠거나 기간이 끝났으면 ③. 틀림 · 지움 · 만료를 구분하지 않고 같은 문구.
> 4. 쿠키가 없거나 무효면 페이지 · 정적 파일 · `/bff/*` 모두 막음(`/bff` 는 401). 미리보기 주소(workers.dev)도 같은 Worker 라 함께 막힘.
> 5. `/logout` → 쿠키를 Max-Age=0 으로 지움.
>
> ## 쿠키
> - 이름 `__Host-admin` · `Path=/; HttpOnly; Secure; SameSite=Lax; Max-Age=604800`(7일).
> - 값은 토큰 원문이 아니라 `토큰이름.만료시각.서명` — Web Crypto HMAC-SHA256, 열쇠는 `ADMIN_SESSION_SECRET`.
> - 매 요청: 서명 · 만료 · **토큰 이름이 아직 목록에 있는지** 확인(목록에서 지우면 쿠키도 바로 무효).
>
> ## 토큰 목록
> - Worker 비밀값 `ADMIN_TOKENS` (JSON): 예) `{"apply-acme-1124": {"token": "<무작위 32자 이상>", "exp": "2027-02-28"}}`. 이름은 회사 · 날짜. exp 없으면 기한 없음.
> - 토큰 비교는 길이 일정 비교(타이밍 차이 없게).
> - **비밀값은 코드 · 저장소 · 로그에 쓰지 않음.** 실제 값 등록은 사용자가 함.
> - 관리 명령(저장소 스크립트, 예: `npm run admin:token -- add apply-acme-1124 --exp 2027-02-28` · `remove` · `list`): 무작위 토큰을 만들고 `wrangler secret put ADMIN_TOKENS --config apps/admin/wrangler.jsonc` 로 목록을 갱신, 새 링크를 출력. 토큰 값을 파일로 남기지 않음. 사용자가 자기 맥에서 돌림.
> - `ADMIN_SESSION_SECRET` 도 사용자가 한 번 등록(명령에 `init` 으로 넣어도 됨).
>
