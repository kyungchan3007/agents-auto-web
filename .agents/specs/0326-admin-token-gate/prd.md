# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 어드민(admin.flapfx.com)은 지원서 · 포트폴리오에 링크로 넘길 곳인데, 지금은 주소만 알면 누구나 들어온다. API Worker 주소로 직접 부르면 어드민용 자료(/activity · /tasks · /geo · /ga4 · /ig · /status)도 토큰 없이 열린다(11-23 lead 확인 · 200)

## 목표
1. 지원 링크 `https://admin.flapfx.com/?t=<토큰>` 로 오면 아무것도 입력하지 않고 들어온다(쿠키를 심고 `?t` 를 지운 주소로 303)
2. 쿠키 없이 주소만으로 오면 막는 화면(①) · 접힌 "토큰 직접 입력"(POST /login)
3. 틀림 · 지움 · 만료 토큰은 같은 문구의 "사용할 수 없는 링크" 화면(③)
4. 쿠키가 없거나 무효면 페이지 · 정적 파일 · /bff/* 모두 막음(/bff 는 401) · 미리보기 주소도 같은 Worker 라 함께 막힘
5. 첫 진입 안내 창(②) 한 번 — 문구는 실제로 하는 일과 맞게(쿠키 저장 · 처음/마지막 접속 시각만 기록 · 개인 정보 안 받음 · 검색 엔진 막음). "추적하지 않는다" · "아무것도 저장하지 않는다" 금지
6. 토큰 이름별 처음 · 마지막 접속 시각만 기록하고 어드민에서 본다(IP · 기기 · 경로 저장 안 함)
7. /logout 으로 쿠키 지움
8. API Worker 를 직접 불러도 어드민용 경로는 어드민 Worker 를 거친 요청만 답한다
9. 토큰 관리 명령(add · remove · list · init)을 사용자가 자기 맥에서 돌린다 — 토큰 값을 파일 · 저장소 · 로그에 남기지 않음
10. 사용자 본인용 토큰 owner: 기한 없음 · 안내 창 없음 · 접속 기록 안 남김 · remove owner 막음 · 다시 만들면 예전 값 무효 · 쿠키 30일(리뷰어 7일)
