# PRD: 나라 물가 요약 칸 · 환율 없음 안내

## 목표
- /prices/[code] 머리 구역 900px 이상에서 왼쪽 아래 약 360px 빈자리에 나라 요약 칸(시안 B · 글래스)을 둔다.
- 환율 없음 안내를 개발자 말이 아니라 방문자 말로: 주지 않는 통화 "{나라} 환율은 아직 제공되지 않습니다" · 늦는 경우 "오늘 환율을 아직 받지 못했습니다".

## 요구
- R1 요약 칸: 제목 "{나라}" · 오늘 기준 · 오늘 환율(통화 단위) · 1만원이면 · 물가(%) · 90일 막대 + "오늘은 90일 중 {낮은 편 · 보통 · 높은 편} ({n}%의 날보다 낮음)" · 값은 페이지가 받는 latest · signal · priceLevels 에서만 · 899 이하 설명 아래 흐름.
- R2 환율 없는 나라: 환율 칸 · 1만원이면 · 90일은 그리지 않고 물가만 크게 + "{나라} 환율은 아직 제공되지 않습니다" · "-" 로 남기지 않음.
- R3 안내 문구(공통 fx-schedule.ts · emptyCopy · checkedAtText 를 쓰는 화면 모두: 직구 계산 · 여행 물가 · 나라 물가 예산 카드 · 통화 상세): 주지 않는 통화 / 늦는 경우 두 갈래 · "한국수출입은행이 … 30분마다 … 사이트를 새로 만들어" 문단과 "자료 없음 · 날짜 시각 확인" 표시를 지움 · "그동안 볼 수 있는 것" 링크는 남김.
- R4 높이 · 위치: 요약 칸이 생겨도 · 입력 · 나라 바꿈으로 오른쪽 카드 · 아래 구역이 움직이지 않음.

## 그대로
