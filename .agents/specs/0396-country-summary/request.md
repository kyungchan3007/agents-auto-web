## 바꿀 것
1. **나라 요약 칸 (900px 이상 왼쪽 설명 아래 · 899px 이하는 설명 아래 흐름 그대로)**
   - 제목 "{나라}" · 오늘 기준.
   - 숫자: 오늘 환율("5.6원" 아래 줄 "/ 100동") · 1만원이면 · 물가("54% 낮음", 노랑 · 세계은행 물가 수준 relative).
   - 90일 막대 + "오늘은 90일 중 {낮은 편 · 보통 · 높은 편} ({n}%의 날보다 낮음)" (0393 과 같은 문구 · '쌈' 금지 규칙).
   - 값은 페이지가 이미 받는 것에서만(환율 latest · 신호 · 물가 수준) · 지어내지 않음.
   - **환율이 없는 나라**(수출입은행이 주지 않는 통화): 환율이 필요한 칸(오늘 환율 · 1만원이면 · 90일)은 그리지 않고 물가만 크게 + 한 줄 "{나라} 환율은 아직 제공되지 않습니다". 빈 칸 · "-" 로 남기지 않음.
   - 칸이 생겨도 오른쪽 카드 · 아래 구역 위치가 입력 · 로딩으로 움직이지 않음.
2. **환율 없음 안내를 방문자 말로 (예산 카드 · 요약 칸 · 같은 안내를 쓰는 곳 모두)**
   - 수출입은행이 주지 않는 통화: "{나라} 환율은 아직 제공되지 않습니다"
   - 값이 늦는 경우(주는 통화인데 오늘 값 없음): "오늘 환율을 아직 받지 못했습니다"
   - 지울 것: "한국수출입은행이 … 30분마다 다시 받고 … 사이트를 새로 만들어 …" 설명 문단 · "자료 없음 · 날짜 시각 확인" 표시.
   - 남길 것: "그동안 볼 수 있는 것" 링크(통화 둘러보기 · 직구 계산).
   - "주는 통화인가"는 지어내지 말고 데이터로 판단(예: 최근 기록에 그 통화가 한 번이라도 있었는지 · 또는 수출입은행 통화 목록 한 곳에 상수로) — sdd 에서 정함.
   - 다른 페이지에 같은 개발자 말투 안내가 있으면 찾아 같은 기준으로(범위는 plan 에 적음).
