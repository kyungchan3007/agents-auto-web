# 계획

## 무엇을 · 왜
- 국내 회사 FDE(Forward Deployed Engineer) 지원용으로 이 프로젝트를 포트폴리오 산출물로 정리한다.
- FDE가 보는 것: 문제 정의 → 외부 시스템 연결 → 빠른 구현 · 운영 → 사고 대응 → 결과 측정 · 전달. 이미 있는 기록에서 이 흐름을 꺼낸다.
- 산출물 (이번 작업 범위)
  1. 사실 기록표 — 포트폴리오에 쓰는 모든 숫자 · 사건의 출처 (docs/portfolio/facts.md)
  2. 케이스 스터디 초안 — 노션 프로젝트 카드와 같은 구성 (docs/portfolio/case-study.md), 노션에는 사용자 확인 뒤에 넣는다
  3. 결정 기록 3~5개 (docs/portfolio/decisions.md)
  4. 구조도 — 데이터 흐름 · 에이전트 팀 흐름 (Figma 또는 이미지)
  5. Figma — 사용자 흐름 · 처음 화면과 새 디자인 비교 · 디자인 토큰
- 이후 작업 (lead 작업서로 넘김): 새 포스터 디자인 구현, "만드는 중" 페이지를 "어떻게 만들었나" 페이지로, README 재작성, 공개 전 비밀값 점검, 시연 영상

## 애매한 곳
- 지원 회사: 국내 (확인됨: "국내회사고 시작하자") → 한국어 산출물만
- 노션 카드: 기존 "프로젝트" 데이터베이스에 새 카드로, 구성은 공부반장 카드와 같게 (가정 · 초안을 먼저 보여 줌 — 사용자 기존 지시)
- 포트폴리오 글 규칙: 표 · 내부 용어 · 한계 항목 없이, 한 줄 불릿, 기록으로 확인한 사실만 (사용자 기존 지시)
