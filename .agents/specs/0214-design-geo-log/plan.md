## 허점
- /geo 페이지 전체 높이가 3,873px(넓은 화면)로 시안의 약 2,100px 에 못 미침 — 맨 위 '이름 바꾼 날 전후 비교(#245)'가 시안(봇 5줄 간단 표)보다 훨씬 길어서(봇 막대 · 일반 질문 16줄 · 브랜드 · 검색 노출 약 1,300px) · 그 구간은 "그대로" 지시라 건드리지 않음. 그 아래 카드 격자는 약 1,440px(예전 표 구간 약 2,800px). 전체를 줄이려면 #245 구간도 접거나 줄이는 후속이 필요(lead 결정).
- /geo 카드: 시안은 5장(2열 + 측정 방법 가로 전체)이고 지금은 카드 4장(AI 답변 · 봇 방문 · 읽은 페이지 · 검색 노출 + 유입) + 아래 기존 '측정 방법' 카드(가로 전체, 그대로). 기존 구조 검사가 요구하는 표시(geo-answers · geo-search · geo-bots · geo-method · geo-questions · 질문별 결과 · 상위 검색어 표 · <details>)는 모두 유지.
- 날마다 막대: 측정 실패(11-08 · 09)는 점선 · 인용이 생기면 막대 위 노란 점. 막대마다 aria-label + 숨은 글(sr-only)로 같은 숫자 — 서버 HTML 에도 있음(e2e). 날짜별 표(서비스 · 질문 판 칸)는 막대로 대체되어 사라짐 — 질문 판 설명 글(3개)은 그대로 둠.
- /log: 모든 구간 같은 카드(radius · 흰 바탕 · 테두리 0 · 여백 24/20 동일 — e2e 가 계산된 스타일 비교). 단계 번호 · 제목은 시안대로 22px. 3초 갱신(useStatus · useTasks)은 건드리지 않음.
- 제목 위 초록 라벨(eyebrow)은 두 페이지 모두 그대로(lead 알림 · e2e 가 색 · 위치 확인).
- 빌드 2번(단계 제목 크기를 시안에 맞춘 뒤 다시 확인) — 요청은 한 번까지.
