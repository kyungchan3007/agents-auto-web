## 1. 기본 hero · 울트라마린 탑승권 (지금 hero 를 바꿈)

- 바탕: 바다 띠 울트라마린(지금 토큰) · 글 종이색 · "11월" · 보기 버튼 · 칩 테두리(고른 것) 해 노랑.
- **문구 (넓은 화면 · 휴대폰 같음)**
  - 제목: "{가장 싼 달}월에 떠나세요." (지금처럼 자료로 바뀜 · 달만 해 노랑)
  - 한 줄: "항공료가 {1년 중 | 받은 달 중} 가장 낮은 달입니다." + 작은 꼬리표 "통계청 국제항공료 지수"
  - 입력창: 자리 글 "어디로 가세요? 도시 · 나라" + 버튼 "보기" (지금 검색 동작 그대로)
  - 입력창 아래 작은 한 줄: "환율 · 물가 · 떠나기 좋은 때를 한 번에"
  - 나라 칩: 도쿄 · 방콕 · 다낭 · 파리 (지금 칩 동작 그대로)
  - **빼는 것**: "통계청 국제항공료 지수로 보면 …가장 낮고 …가장 높습니다" 문장 · "어디로 가세요? 아래 칸에 …" 문장(HERO_GUIDE.lead) · "가입 없이 무료 · ↓"(HERO_GUIDE.free). 사용자 지시라 문구 테스트는 새 문구에 맞게 고친다.
- **오른쪽 그림** (그림은 장식 · 글 읽기에 필요 없음 → aria-hidden 또는 짧은 label)
  - 탑승권 세 장 겹침(맨 앞이 흰 카드 + 남색 떼는 쪽). 카드 내용: ICN 인천 → 공항코드 도시 · 오늘 환율 "1,475원 / 1유로" · 떠나기 좋은 때 "11월" · 떼는 쪽 "최근 90일 중 83% 의 날보다 환율이 낮습니다" + 막대.
  - **값은 사이트에 이미 있는 실제 값**(오늘 환율 · 90일 비교 · 떠나기 좋은 달). 시안 숫자는 예시. 받지 못한 값은 빈 칸(지어내지 않음 · AGENTS 규칙 7).
  - 뒤: 흰 점선 비행 노선(큰 곡선) + 그 위를 도는 작은 비행기(9초 한 바퀴) · 은은한 밝은 파랑 빛. **노란 원(해 · 달) 넣지 않음**(사용자: 추석 느낌).
  - 주변 흰 꼬리표 셋: "1만원 → ¥1,063" · "€1 = 1,475원" · "฿100 = 4,120원" 처럼 오늘 환율로 계산한 값(살랑 위아래).
- **모션**
  - 첫 등장: 제목 → 한 줄 → 입력창 → 칩이 아래에서 차례로(0.7초 · 0.06~0.08초 간격).
  - 탑승권: 묶음이 천천히 떠 있음 · 3.6초마다 맨 앞 장이 왼쪽 아래로 넘어가고 다음 도시가 앞으로(파리 → 도쿄 → 방콕 → 다낭). 칩을 누르면 그 도시 탑승권으로 넘어감(6초 동안 자동 넘김 멈춤).
  - 움직임 줄이기: 넘김 · 비행기 · 꼬리표 움직임 없음 · 첫 장 그대로.
- **반응형 (사용자가 두 번 지적 · 꼭 지킬 것)**
  - 1200px 이상: 글 왼쪽 · 탑승권 오른쪽. 900~1199: 나란히 · 글 칸 최대 47vw · 탑승권 폭 40vw. 899 이하: 탑승권을 글 아래 가운데(최대 520px).
  - 탑승권 안 글자 · 여백은 **카드 폭에 비례(container query · cqw)**, 작은 글자 최소 8.5~9px, 카드는 overflow hidden. 화면 폭(vw) 기준으로 두면 실제 휴대폰 글꼴에서 넘침(시안에서 실제로 일어남).
  - 여백: 넓은 화면 hero 높이 약 560px(지금보다 줄임) · 휴대폰은 메뉴와 제목 사이 짧게, 탑승권이 첫 화면에 걸쳐 보이게.
- 참고 값은 시안 CSS(`.sea`, `.pass`, `.passes`, `.fxtag`, `.route-bg`) 그대로 옮기면 됨. 색 · 그림자는 토큰으로.

## 2. 블랙프라이데이 hero · 검정 영수증 (기간 한정)

- **보이는 기간: 배포 즉시 ~ 2026-12-01(화) 17:00 KST** (미국 서부 사이버먼데이 끝). 그 뒤 자동으로 기본 hero.
  - 사이트는 정적 빌드이므로 **브라우저에서 지금 시각으로 고른다**(빌드 시각 아님). 첫 그림 깜빡임이 없게 처리(예: 서버 HTML 은 기본, 기간이면 클라이언트에서 교체 · 또는 둘 다 그리고 CSS 로 하나만). 방법은 lead 판단 · 사유를 plan 에.
  - 기간 시작 · 끝 시각은 상수 한 곳(+ 테스트: 끝 1초 전 블프 · 끝 시각부터 기본).
- 바탕 검정 · 포인트 해 노랑. 글 흰색 · 보조 회색.
- **문구**
  - 제목 위 라벨(노란 알약): "블랙프라이데이 11.27 · 사이버먼데이 11.30"
  - 제목: "**$200** 넘기 전에 / 먼저 계산하세요." ($200 해 노랑)
  - 한 줄: "미국 직구는 $200까지 면세입니다." + 꼬리표 "관세청 · 목록통관 기준"
- **입력창 = 계산기** (직구 계산 기능의 규칙 그대로 · 새 세금 규칙 없음)
  - "$" + 금액 입력 + 선택칸(미국 목록통관 $200 / 일반 · 그 밖의 나라 $150) · 값 · 출처는 `features/import-calc` 의 rules 한 곳(IMP-03) 재사용.
  - 입력 즉시: "약 N원" · "면세 · 한도까지 $X 남음" 또는 "한도 초과 $X · 관부가세 대상" · 한도 막대(초록 → 빨강). 입력 전 안내는 흐린 작은 글 "원화로 얼마인지 바로 봅니다".
  - 환율: 이번 주 관세청 과세환율이 있으면 그것, 없으면 수출입은행 + "예상 금액"(IMP-06 그대로). 아래 작은 글: 환율 기준 · 출처 · "같은 판매자에게 같은 날 산 물건은 합쳐서 봅니다 · 예상 금액".
  - 입력값은 보내거나 저장하지 않음(IMP-01).
- **오른쪽 그림: 감열지 영수증** (3D 기기 없음 · 사용자: 단말기 · 휴대폰 3D 는 장난감 같음)
  - 미색 종이 + 고운 종이 결 · 위아래 톱니 끝 · -3.5도 기울기 · 그림자 · 뒤에 어두운 영수증 한 장.
  - 내용(고정폭 글꼴): FLAPFX DIRECT / 해외 직구 · 장바구니 확인 / 날짜 시각 · BLACK FRIDAY / 품목 3줄 / 소계 · 면세 한도(미국 목록통관) $200.00 · **합계** · 원화 환산(환율) · 점선 한도 막대 · 한도까지/한도 초과 / 바코드 · 번호 · "예상 금액 · 실제 세액은 관세청 기준".
  - **모션 (한 번만 · 반복 없음)**: 0.5초 뒤부터 품목이 0.85초 간격으로 한 줄씩 찍히고 종이가 길어짐 · 줄마다 소계 · 합계 · 원화가 0.7초 카운트업 · **카운트업이 끝날 때마다 그때 합계로 도장을 다시 찍음** → 면세 · 면세 · 과세($149 · $187 · $211). 도장은 바코드 오른쪽 빈자리.
  - 품목은 예시 장바구니(에스프레소 머신 $149 · 원두 $38 · 머그 $24) · 원화는 실제 환율로 계산.
  - 움직임 줄이기: 다 찍힌 상태 + 마지막 도장.
- 반응형: 넓은 화면은 오른쪽, 899 이하는 계산기 아래. 기본 hero 와 같은 전 폭 검사.
