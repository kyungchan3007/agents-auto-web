# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- /currencies 에는 검색창이 없다. 계산 함수(`matchCurrency` · 코드와 통화 이름만)와 훅의 query 는 남아 있지만 디자인 변경(0170) 때 화면에서 빠졌다.
- 여행 가는 사람은 "엔화"나 "도쿄"처럼 나라 · 도시로 생각하는데, 통화 코드를 모르면 22개 목록을 눈으로 훑어야 한다.

## 목표
- /currencies (목록 · 상세 모두 보이는 왼쪽 영역)에 검색창 하나.
- 통화 코드(USD) · 통화 이름(달러 · 엔화) · 나라(일본) · 도시(도쿄)로 찾는다.
- 입력하는 동안 자동완성 목록이 뜬다. 위아래 화살표 · 엔터 · 마우스 · 모바일 터치로 고르면 그 통화 상세(`/currencies/CODE`)로 간다.
- 각 제안 줄에는 왜 나왔는지 보인다 (예: "JPY 엔화 · 일본 도쿄").
- 결과가 없으면 "찾는 통화가 없습니다"와 고를 수 있는 통화 수(빌드 때 받은 실제 수)를 보여 준다.
- 접근성 콤보박스 규칙(WAI-ARIA combobox · listbox · aria-activedescendant · Esc 로 닫기)을 따른다.

## 비목표
- 서버 검색 · 새 API 없음 (빌드 때 받은 목록 안에서만).
- 지역 · 정렬 · 즐겨찾기 버튼을 되살리지 않는다.
- 환율이 없는 나라(통화 null)는 결과에 넣지 않는다 (가정 · 고르면 갈 곳이 없음).

## 애매한 곳
- 도시 표는 인트로 출발 안내판 것(`INTRO_CITIES`)을 공용 `@hav/shared/travel` 로 옮겨 같이 쓴다 (확인됨: 이슈 "새로 만들지 않음").
- 여러 나라가 한 통화를 쓰면(EUR) 한 줄로 묶고 맞은 나라 · 도시만 보여 준다 (가정).
- 제안 줄 수는 최대 8개 (가정).
