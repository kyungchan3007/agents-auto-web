# 작업 요청 — 여행 타이밍 그래프 읽기 쉽게  [Quick · 작업 0181]

## 사용자 요청 원문 (request.md 에 그대로 · 사용자가 홈 여행 타이밍 그래프 캡처를 함께 보냄)
여기도 가격이 없네 없으니까 그냥 줄만 그어 놓은거 같고 지금 안에 곡선이 3개 인데 범례가 있긴한데 구분이 잘 안돼 보기가 힘들어

## 원인 (확인함)
- `apps/web/src/features/travel-price/components/flights-graph.tsx`: 세 선(국제항공료 · 해외단체여행비 지수 · 원/달러 월평균)을 각자 최저~최고로 늘려 그려서 공통 세로축이 없고, 숫자가 그래프 어디에도 없음. 가로 눈금선 3개도 값과 무관.
- 범례는 그래프 아래 작은 글자 · 국제항공료(울트라마린)와 해외단체여행비(청록)가 같은 굵기 3 이라 구분이 어려움. 가로축도 처음 · 끝 달만.
- 이 부품은 홈 맨 위 여행 타이밍과 /flights 에서 같이 씀.

## 할 일 (claude-desktop 결정 · 구현은 builder 한 명)
1. **주인공은 국제항공료 한 선**: 울트라마린 굵기 3 유지. 나머지 둘은 굵기 2 · 옅게(불투명도 약 0.55) 깔아 배경 정보로.
2. **숫자 표시 (통화 그래프 최고 · 최저와 같은 방식)**: 국제항공료 선에
   - 노란 점(가장 싼 달)에 "2025-05 최저 · 지수 87.3" 처럼 달 · 값 라벨
   - 가장 비싼 달에 "최고 · 지수 OO" 라벨
   - 마지막 달 끝에 최근 값 라벨
   - 지수 기준(예: 2020=100)은 원자료 기준 그대로 그래프 위 작은 글자 한 줄 ("지수 · 2020년 = 100 · 실제 요금이 아닙니다"). 기준 연도는 수집 코드 · 원자료에서 확인, 모르면 지어내지 말고 "지수" 만.
3. **선 끝에 이름 직접 표시**: 각 선 오른쪽 끝에 "국제항공료 103.2" · "단체여행비 112.4" · "원/달러 1,420원" 처럼 이름 + 최근 값. 끝 라벨끼리 겹치면 위아래로 밀어 띄움. 휴대폰에서 공간이 없으면 끝 라벨 대신 아래 범례에 최근 값을 붙임.
4. **범례를 눌러 강조**: 범례 칩을 누르면 그 선만 진하게 · 나머지 흐리게 (다시 누르면 원래대로). button · aria-pressed. 범례 칩에 최근 값도 표시.
5. **값과 무관한 가로 눈금선 3개 제거** (세 선이 단위가 달라 공통 눈금이 없음 — 그래프 위 한 줄로 "선마다 단위가 달라 모양만 비교합니다" 안내).
6. **가로축 달 눈금**: 처음 · 끝만이 아니라 6개월 간격 정도로.
7. 3D 비행기 · 노란 점 · 색 팔레트 · 밝은 화면만은 그대로. 값이 없는 선은 그리지 않고 라벨도 지어내지 않음.
