# PRD: 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 어드민 작업실(/log)의 "실시간 기록" 칸은 최근 머지 3줄만 보여 주고, 같은 내용이 "지난 작업"에도 있어 쓸모가 적다(사용자 "필요없을거 같긴해").

## 목표
- 같은 자리(팀 칸과 같은 높이 그대로)를 두 부분으로 바꾼다.
  1. 오늘 팀이 한 일: 가장 최근 "오늘 할 일 YYYY-MM-DD" 이슈의 체크 항목 · 끝남/남음 · "N개 중 M개 끝남" · 이슈 링크.
  2. 최근 자동 검사: 최근 20번 gate 실행의 통과 · 실패 수, 걸린 시간(가운데 값 · 최근 한 번), 실패한 실행은 PR 링크.
- 받지 못한 값은 "자료 없음".

## 비목표
- 지난 작업 · 작업 이름 칸은 그대로(github_items 그대로 씀).
- 운영 사이트(apps/web)는 바꾸지 않는다.

## 애매한 곳
- 걸린 시간: 가운데 값과 최근 한 번 둘 다 보인다 (확인됨: 시안 2번 승인).
- "gate 실행" = checks.yml 워크플로 실행(PR · main) 중 끝난 것 최근 20번. 취소 · 건너뜀은 세지 않는다 (가정).
- 체크 항목 글은 이슈에 적힌 굵은 머리("**...:**")만 보인다 (확인됨: 시안 승인). 굵은 머리가 없으면 항목 글 앞부분.
- 실패한 검사: 브랜치 이름 + 실행 링크, 브랜치로 PR 을 찾으면 PR 링크 (확인됨: 시안 3번 승인). 최대 3줄 (가정).
- 작업 종류 ③(숫자 · 동작): 요구마다 기능 테스트.

## 완료 기준

- [ ] "작업 NNNN 머지 · 제목" 줄이 작업실에서 사라짐 · 지난 작업 칸은 그대로
