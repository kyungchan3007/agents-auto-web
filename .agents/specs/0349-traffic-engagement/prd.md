# PRD: 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 이탈 줄이기 묶음이 효과가 있는지 볼 숫자가 없다. 어드민 유입 화면은 페이지뷰만 보여 준다.

## 목표
- 어드민 /traffic 에 "페이지별 머무름" 표(시안 4 · index.html 의 4번 표 틀): 페이지 · 페이지뷰 · 참여율 · 이탈률 · 다른 페이지로 넘어감, 그리고 기준일 값 대비 오르내림.
- 기준일: 작업 0344(나라별 여행 물가)가 운영에 나가기 전 날. 이번 main 반영일 전날로 고정.

## 비목표
- 운영 사이트 변경 · 새 비밀값 · 워크플로 변경 · DB 스키마 변경.

## 애매한 곳
- "다른 페이지로 넘어감": 세션당 페이지뷰(screenPageViewsPerSession) 로 본다 (가정 · GA4 에 "다음 페이지" 지표는 없음).
- 기간: 지금 다른 보고서처럼 최근 28일 합계 (가정).
- 작업 종류 ③: 요구마다 기능 테스트.
