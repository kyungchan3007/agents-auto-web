# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다. 화면 기준은 [handoff.md](handoff.md) "고치면" 절.

## 문제
- 통화 "둘러보기"가 테두리 카드 22장이라 환율 숫자가 없고 "하위 N%" 글이 다 비슷해 통화끼리 비교가 안 된다(사용자: "별 의미가 없어 보여").

## 목표
- 둘러보기를 표로: 통화(국기 · 이름 굵게 · 코드 작게, 넓은 화면만) · 오늘 환율(오른쪽 · 굵게 · "원") · 90일 최고보다(%, 소수 한 자리 · 넓은 화면은 막대 함께 · 휴대폰은 숫자만)
- 많이 내린 순서 · 넓은 화면 두 단(각 머리 줄) · 휴대폰 한 단 · 줄 전체가 상세 링크 · 지금 보는 통화 표시
- "최근 90일 중 하위 N%" 글 삭제 · 화면 낭독에는 환율과 내린 폭
- 목록 페이지와 상세 페이지에 같은 표

## 비목표
- 흐름 선(A안) · 통화 검색 최근 칩 · 표 밖의 통화 페이지 구성

## 자료 규칙
- 90일 최고보다 = (오늘 값 − 최근 90일 최고) ÷ 최근 90일 최고. 받은 기록으로만 계산. 기록이 없거나 부족하면 "—" · 오늘이 최고면 "최고". 지어내지 않는다.
- D1 읽기를 늘리지 않는다 — 이미 읽는 `/signal`(전체) 응답에 90일 최고를 싣는다.

## 애매한 곳
- 막대 길이 기준: "가장 많이 내린 통화가 꽉 참"(handoff) — 그대로 (가정 아님 · 작업서 값).
- "부족한 기록"의 기준: 신호 계산의 기존 기준(minCoverage 로 신호가 null 이 되는 경우)을 따른다 (가정).
- 같은 내린 폭이면 순서: 기존 지역 순서로 (가정).

## 완료 기준
- [ ] PR 최신 커밋 CI gate SUCCESS (평소 PR · 전체 e2e 는 하루 마무리에서)
- [ ] `/signal` 전체 응답 항목에 90일 최고(선택 필드) · 계약 테스트
- [ ] 표 · 열 · 순서 · 두 단/한 단 · 빈 값 "—" · "최고" · 지금 보는 통화 표시 · 줄 링크 기능 테스트
- [ ] 화면 낭독 이름에 환율과 내린 폭
