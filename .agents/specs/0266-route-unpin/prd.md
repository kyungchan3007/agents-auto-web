# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 판정 기준은 원문과 [handoff.md](handoff.md) "고치면" 절이다. 11-19 "시안 그대로 적용"(스크롤 고정 노선)을 사용자가 시안 40 을 보고 바꿨다.

## 문제
- 여행 물가 노선이 화면에 붙어 스크롤 2.2장을 붙잡아, 스크롤해야 정거장이 바뀌고 페이지 이동이 막힌 느낌이다.
- 카드 아래 테두리가 잘려 보이고, 노선 아래 구간(굵은 남색 선)과 바로 붙어 굵은 막대처럼 보인다.

## 목표
1. 스크롤 고정 해제 — 구간은 내용 높이(넓은 화면 약 600px)만 · 스크롤로 정거장이 바뀌지 않음
2. 나라 단추(`route-stop`)로 고름 — 비행기 이동 · 국기 · 이름 · 숫자 넘어가기 움직임 재사용 · 같은 값이면 비행기 제자리(0251) 유지 · 처음엔 첫 정거장(가장 싼 나라)
3. 휴대폰에도 단추 줄 — 제목 아래 가로로 밀 수 있는 한 줄 · 문서 가로 넘침 없음
4. 제목 "나라별 물가 노선" · 설명 "나라 이름을 누르면 그 나라로 갑니다 · 싼 나라에서 한국을 지나 비싼 나라 순서입니다" · aria-label 맞춤
5. 노선 구간과 아래 세 칸 목록 사이 간격 넓은 화면 96px · 휴대폰 72px (굵은 선 그대로)
6. 정거장 카드 아래 테두리가 잘리지 않게(양옆 mx-px 와 같은 방식) · 왼쪽 굵은 색 띠 그대로
- JS 없이도 첫 정거장 카드와 물가 자가 보임

## 비목표
- 노선 밖 구성 · 물가 자 모양 · 단추 모양 변경

## 애매한 곳
- 움직임 줄이기 화면(`route-static` · 카드 모두 펼친 목록)을 둘지 새 방식(단추 · 움직임 없음)으로 합칠지 — builder 가 판단하고 PR 에 적는다(작업서가 맡김).
- 휴대폰 단추 줄 모양 — 시안 없음 · 기존 단추 모양을 가로 스크롤 한 줄로 (가정) · PR 에 미리보기 경로.

## 완료 기준
- [ ] PR 최신 커밋 CI gate SUCCESS (평소 PR)
- [ ] 스크롤해도 정거장이 바뀌지 않음 · 구간 높이가 화면 여러 장이 아님
- [ ] 단추를 누르면 카드 · 비행기가 그 나라로 · 처음 첫 정거장 · 같은 값 제자리
- [ ] 휴대폰 단추 줄 보임 · 가로 넘침 없음
- [ ] 새 제목 · 설명 · aria-label
- [ ] 아래 구간 간격 96/72 · 카드 아래 테두리 보임
