## 허점
<!-- 이번 작업에서 드러난 실수·구멍. 같은 허점이 두 번 나오면 하네스(검사·훅·린트)로 막는다 -->
- 명령 하나를 `&&` 로 길게 이어 쓰다가 앞 명령(git rm)이 실패해 뒤 파일 쓰기가 통째로 빠진 적이 있음 — 파일 쓰기는 별도 명령으로 나눔
- 사진 요청 0 은 e2e 로 잡혔지만 원인(링크 미리받기)은 HTML 에서 안 보임 — 요청 URL 을 출력해 찾음
- 웹킷(사파리) 확인은 못 함 (playwright webkit 없음)
- (파인 홈) 빌드를 가짜 API 로 다시 돌릴 때 turbo 가 입력이 같다고 보고 **이전 빌드를 다시 재생**해 항공료 자료가 빈 채로 e2e 6건이 실패함(자료 때문) — `npm run build -- --force` 로 우회하니 34건 모두 통과. 가짜 API 를 바꾼 뒤에는 꼭 --force.
