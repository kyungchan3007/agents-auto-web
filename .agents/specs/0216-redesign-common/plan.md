# 계획 — 작업 0216 새 디자인 공통 (파랑 메뉴 · B 로고 · 글자판 · 카운트업 · 들어오기)

## 무엇을 · 왜
- 사용자가 고른 새 디자인(DECISIONS.md)을 다섯 페이지에 옮기기 전에, 모든 페이지가 함께 쓰는 바탕을 먼저 만듭니다. 0217~0221 은 이 브랜치 위에서 시작합니다.
- 메뉴 띠: 모든 페이지에서 브랜드 파랑(#2438A8 · 토큰 cheap) 면 · 메뉴 글자 흰색 · 지금 페이지는 흰 알약(파랑 글자) — 시안 `C/header-blue.html` · `C/shots/header-blue-*.png`. 휴대폰 펼친 메뉴도 파랑 면.
- 로고: 2안 B 로고 — 배지 없이 'flap' 흰색 + 'fx' 노랑(sun) 글자 (`logo-and-summary.html` 2안). 메뉴 링크 이름 · 순서는 그대로.
- 글자판(FlapBoard): B 모양으로 — 짙은 판 · 칸마다 가운데 이음선 · 노랑 글자 (`B/_src/base.css` 의 `.flap`). 지금 부품이 이미 거의 같으므로 차이(칸 색 · 흰 글자 줄 선택지 `w` · 칸 크기 비율)만 맞춥니다. 처음 한 번만 넘어가는 규칙 · 첫 그림은 최종 글자 · 화면 읽기 한 문장 규칙은 그대로.
- 카운트업 부품: 숫자가 화면에 들어올 때 한 번, 최종 값 근처에서 시작해 약 1초 동안 최종 값으로. 소수점 자리 · 쉼표 · 단위 그대로. 서버 첫 그림과 움직임 줄이기는 바로 최종 값. 화면 읽기는 최종 값만 읽음(aria). 글자 폭이 흔들리지 않게 tabular-nums.
- 들어오기 부품: 화면에 들어올 때 한 번, 지정한 방향(기본 왼쪽)에서 제자리로 미끄러져 들어오며 끝에서 느려짐(ease-out 약 0.7초). 움직임 줄이기면 바로 제자리. 첫 그림에서 내용이 숨지 않게(자바스크립트가 못 돌아도 보임).
- 카운트업과 함께 움직일 것(홈 환전 타이밍 동그라미)을 위해, 카운트업 진행 비율(0→1)을 함께 쓸 수 있게 훅으로도 꺼냅니다.
- 국기 부품(Flag · CurrencyFlag) 재사용 확인만 — 0217 · 0219 에서 쓸 크기가 되는지 적어 둡니다.
- 작업 보드에 0216~0221 여섯 줄을 미리 넣고, 이미 머지된 0204 · 0205 · 0208~0215 줄을 머지됨으로 고칩니다 (뒤 작업들이 같은 줄을 고쳐 충돌하지 않게).

- 메뉴 높이: 지금 높이(h-14 · sm:h-18) 그대로 (가정 — 시안도 같은 높이).
- 첫 페이지 맨 위 뒤 화면 색: 홈 · 여행 물가(B)는 메뉴와 첫 화면이 한 면으로 이어지고, A 페이지는 메뉴 아래부터 흰 면 — 이건 각 페이지 작업(0217~0221)에서 맞춥니다. 0216 은 메뉴 띠만.
