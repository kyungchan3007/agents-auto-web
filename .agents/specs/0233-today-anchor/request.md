## 고칠 것
- 메뉴 "오늘 환율"을 누르면 "도착지별 환전 타이밍" 구역의 라벨 · 제목이 고정 메뉴 바로 아래에 보여야 한다(사용자 그림 2 구도). 넓은 화면 · 휴대폰 모두.
- 방법은 lead 가 정한다. 참고할 점
  - `#today` 는 e2e(`country-pick.spec.ts` · `intro.spec.ts`)가 탑승권 카드를 가리키는 데 쓰고, 인트로도 `/#today` 를 "위치 링크로 들어옴"으로 본다(`features/intro/lib/entry.ts` · `hooks/use-intro-enabled.ts`). id 를 옮길지 링크를 바꿀지에 따라 같이 손봐야 한다.
  - 고정 메뉴 높이만큼 스크롤 여백이 필요하다(다른 곳은 `scroll-mt-(--hav-nav-h)` 를 씀).
  - 환전 타이밍 카드는 화면 아래에 있으면 요약 알약으로 접혀 있다(작업 0228). 링크로 도착했을 때 접힌 채 남지 않고 펼쳐져야 하며, 펼쳐지면서 도착 위치가 밀리면 안 된다.
- 바깥에 퍼진 `/#today` 주소(사이트맵 · 공유된 링크)가 있으면 계속 맞는 자리로 가야 한다.
