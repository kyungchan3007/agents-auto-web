# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 사용자가 통화 상세(/currencies/[code]) 새 디자인으로 시안 A 를 골랐고, 다른 통화로 가는 길을 "둘 다"(위쪽 검색 + 국기 칩 줄, 맨 아래 다른 통화 목록)로 정했습니다.

## 목표 (시안 A/currency.html · A/shots/currency-1280.png · -390.png)
- 머리: 국기 + "미국 달러 · USD" 라벨 · "달러(USD) 환율" · 아주 큰 오늘 값(카운트업) · 상태(색 점 + "하위 32% · 보통") · 기준 글(지금 문구)
- 위쪽 다른 통화: 통화 검색(자동완성 · 키보드 위아래 · Enter · Esc · 화면 읽기 combobox) + 국기 칩 줄(자주 보는 통화 · 지금 통화 표시)
- 1년 최저 · 최고 · 평균 한 카드: 비행 경로 줄 — 왼쪽 최저 · 오른쪽 최고 · 가운데 평균 눈금 · 오늘 위치에 비행기 점. 최저 · 최고 카운트업
- 오른쪽 탑승권 "실제로 바꿀 때": 짙은 남색 · 금액 입력 · 빠른 금액 칩 · 결과는 글자판(B 모양) · 아래 매매기준율 안내(지금 문구). 지금 환전 계산 기능 그대로 · 결과 금액 카운트업(처음 들어올 때만)
- 1년 흐름 그래프: 선이 그려지며 나타남(한 번) · 최고 · 최저 · 평균 표시 · 1개월/3개월/1년 탭 지금 기능 유지
- 맨 아래 다른 통화 목록(지금 목록 부품 재사용)
- 모든 통화 페이지에 같은 틀 · 자료 없는 값은 지금처럼 빈 값

## 비목표
- 시안 영문 라벨(BOARDING PASS · EXCHANGE · FROM · USD / TO · KRW)은 넣지 않음 — 사용자 확인 목록
- "오늘 1,338.8원 — 1년 최저 쪽 가까이에 있습니다" 같은 새 문장은 넣지 않음 — 사용자 확인 목록 (지금 페이지에 같은 뜻 문장이 있으면 그것을 씀)
- 사진 쓰지 않음 · 통화 목록 페이지(/currencies)는 바꾸지 않음(메뉴만)

## 애매한 곳
- 국기 칩 줄의 통화: 홈 도착지 4개(JPY · USD · EUR · THB) + 지금 통화 (가정)
- 검색 자동완성 목록: 지금 currency-search 부품이 있으면 그것을 키워 씀 (가정)
