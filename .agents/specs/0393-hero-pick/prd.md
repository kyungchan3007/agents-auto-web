# PRD: 기본 hero 고른 곳 정보 · 숫자 칸 · 가운데 정렬

## 목표
- 기본 hero 에서 나라 · 도시를 고르면 그 곳 정보(탑승권 · 숫자)가 바로 보인다. 0384 에서 오늘 환율 카드를 지운 뒤 고른 결과를 보여 줄 곳이 없어진 것을 메운다.
- 탑승권을 못 보는 사용자도 칩 아래 숫자 칸(글래스)에서 환율 · 1만원이면 · 물가 · 90일 위치를 본다.
- 제안 목록이 입력칸 · 칩 · 글과 겹치지 않는다.
- 600~899px 에서 두 hero(기본 · 블프)의 글 칸이 탑승권 · 영수증과 같은 중심선에 선다.

## 요구 (작업서 번호)
- R1 고르기: 칩 · 제안 클릭 · Enter · 보기가 같은 함수 · 모션은 처음 모션 하나(맨 앞 장만 data-s=out 0.65초로 사라지고 고른 장이 앞) · 한 번만 · 끊김 · 반복 없음 · 넘김 중 누르면 끝난 뒤 한 번 · 네 도시 밖이면 그 곳 장 하나 만들어 맨 앞(덱 밖 장은 하나만) · 고른 뒤 자동 넘김 멈춤 · 라벨 "· 고른 곳" · 탑승권 링크 "{도시} 항공권 날짜 보기 ›" · 저장(useTripSwitcher) 유지.
- R2 숫자 칸: 안 골랐을 때 맨 앞 탑승권 도시를 따라감(비지 않음 · 높이 안 변함) · 제목 "{나라} {도시}" · 오늘 환율 · 1만원이면 · 물가(%) · 90일 막대 · 위치 문장 · 나라 페이지 링크(pageCodes) · 값은 홈이 이미 받는 latest · signal · priceLevels 에서만 · 90일 최저(min)는 목록 응답에 없음 → 계약 · API 바꾸지 않음 · 받지 못한 값 "-" · 글래스 값은 사용자 확정 그대로.
- R3 제안 목록: 입력칸 아래 8px · 흰 불투명 · 쌓임 순서 위 · 줄 오른쪽 공항 코드(없으면 빈 칸) · 검색은 지금 그대로.
- R4 899px 이하 가운데 정렬(기본 · 블프): 글 칸 최대 600px 가운데 · 좌우 22px · safe-area · 입력칸 · 숫자 칸 · 블프 계산 칸 꽉 채움.

## 그대로
- 기본 hero 문구 · 칩 네 개 · 탑승권 모양 · 안 골랐을 때 자동 넘김 · 캐러셀 · 헤더 색 · 블프 장(가운데 정렬만 · 통관 고정 글자 0389 유지).

## 진행
- develop 머지까지(main 은 사용자가 말할 때) · 릴리스 없음 · 머지 뒤 미리보기 주소를 사용자에게(최신 빌드 확인 뒤).
