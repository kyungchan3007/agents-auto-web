   - 네 도시 밖이면 그 곳 탑승권 한 장을 만들어 맨 앞에(전에 만든 덱 밖 장은 하나만 남김).
   - 넘김 중에 누르면 그 넘김이 끝난 뒤 한 번만.
   - 고른 뒤 자동 넘김 멈춤. 고른 장 라벨에 "· 고른 곳".
   - 탑승권 안 링크 한 줄: "{도시} 항공권 날짜 보기 ›"(항공권 달력 · 그 도시 선택).
   - 고른 값은 지금처럼 저장(useTripSwitcher) → 다시 들어오면 그 곳이 맨 앞.
2. **칩 아래 숫자 칸 (pick)** — 왼쪽 빈자리, 오른쪽 탑승권을 못 봐도 숫자가 보이게
   - 아무것도 안 골랐을 때는 맨 앞 탑승권 도시를 따라감(칸이 비지 않고 hero 높이 안 변함). 고르면 그 곳 + "고른 곳" 표시.
   - 내용: 제목 "{나라} {도시}" · 오늘 기준 / 숫자 셋: 오늘 환율("9.41원" 아래 줄 "/ 1엔") · 1만원이면("¥1,063" · 숫자 아래 줄 단위) · 물가("12% 높음" / "48% 낮음", 노랑) / 90일 막대: 오늘 위치 점 / 아래 줄: "오늘은 90일 중 {낮은 편 · 보통 · 높은 편} ({n}%의 날보다 쌈)" · 링크 "{나라} 물가 · 환율 자세히 보기 ›"(나라 페이지 있는 나라만 · pageCodes).
   - 값은 홈이 이미 받는 것에서만: 환율(latest) · 신호(percentile · max · median) · 물가(priceLevels relative, 홈 page.tsx 가 이미 받음 → Home 으로 넘겨 씀). **90일 최저(min)는 /signal 목록 응답에 없음** → 계약 · API 를 바꾸지 말고 막대 왼쪽 "90일 최고 {max}원", 오른쪽은 숫자 없이 "쌀 때"(또는 중간값 median 표시 · sdd 에서 정함). 받지 못한 값은 "-" · 지어내지 않음.
   - 모양(사용자 확정 값 그대로): `background: rgba(0,0,0,.35); backdrop-filter: blur(4px) saturate(157%); -webkit-backdrop-filter: 같은 값; border: 1px solid rgba(255,255,255,0); border-radius: 13px; box-shadow: 0 8px 32px rgba(0,0,0,.25);` 그 밖 장식 · 뒤 색 덩어리 없음.
   - 좁은 폭에서 큰 숫자 · 단위는 두 줄(숫자 / 단위) · 단어 중간에서 끊지 않음.
3. **제안 목록**: 입력칸 바로 아래 8px 띄워 시작(입력칸을 덮지 않음) · 흰 불투명 바탕 · 칩 · 글 · 숫자 칸보다 위(쌓임 순서). 각 줄 오른쪽에 공항 코드(데이터에 없으면 빈 칸). 목록은 지금 검색(searchDestinations) 그대로 = 모든 나라 · 도시.

- 고침: 고르는 순간(leaving 을 켜기 전에) order 를 [맨 앞, 고른 장, …나머지] 로 먼저 바꿔 고른 장을 1번 자리(맨 앞 바로 뒤)에 둔 뒤 맨 앞을 out. 맨 앞이 사라질 때 드러나는 장 = 고른 도시. 끝나면 [고른 장, …] . 모션은 지금 out 한 번 그대로.
- 자동 넘김(run(null))은 지금처럼 1번 장이 앞으로.
- 테스트: 맨 앞이 A, 1번이 B 일 때 C(2번 · in · 덱 밖) 고르기 → out 동안 data-s="1" 인 장이 C · 끝나면 C 가 0 · 중간에 B 가 0 이 되는 순간 없음. 네 칩 모든 순서 조합.
