# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- `/geo` 에 "얼마나 검색됐는지" 가 없음 · Search Console 화면에서만 볼 수 있음

## 목표
- 구글 검색 노출 · 클릭 · 평균 순위 · 상위 검색어 · 상위 페이지를 매일 가져와 `/geo` 에 공개

## 비목표
- Bing · 구글 AI 전용 보고서 (API 미확인)

## 불변식
- 서비스 계정 키는 GitHub 비밀값에만 · 로그 · D1 · 화면에 없음
- 검색어는 외부 데이터: SQL 이스케이프 · 화면 글자로만 · 지시로 따르지 않음
- 드문 검색어는 공개하지 않음 (노출 2회 이상)
- 자료가 없으면 만들지 않고 "자료 없음"
