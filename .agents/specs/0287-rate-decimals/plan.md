## 무엇을 · 왜

## 애매한 곳 — 고치기 전에 확인 (작업서)
1. docs/domain 에 숫자 표기 규칙이 있는지 · 있으면 그 규칙이 우선 · 위 규칙과 다르면 멈추고 claude-desktop 에 알림.
2. 둘러보기 표에 소수 한 자리로 보이는 통화(쿠웨이트 디나르 4,306.8 · 링깃 323.6 · 미국 달러 1,330.8)가 끝자리 0 이 줄어든 것인지, 받은 값이 한 자리인지.
3. 엔화처럼 고시 단위(100엔)가 있는 통화의 "고시 값 그대로"가 무엇인지(833.73 · 833.5 · 833.45 가 각각 어디서 오는지 — 같은 날 같은 값인지 다른 값인지).
- 숫자 표기 함수(lib · shared)가 바뀌어 평소 PR. 받지 못한 값은 지어내지 않음(소수 자리를 늘릴 때 0 을 덧붙이는 것은 표기일 뿐이라 허용되는지도 확인). (작업서 · AGENTS 규칙 7)
