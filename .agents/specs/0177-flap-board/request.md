# 작업 요청 — 홈 첫 화면: 출발 안내판 (사진에 걸치기)

## 사용자 요청 원문 (request.md 에 그대로)
아 뭔가 지구뒤에 있는 파란색 배경이 왜이리 안어울리는거 같지 음 좋은 아이디어 없니?
아 색갈 다른거 없을까? 아이디어좀 내봐 아니면 지구본을 없앤다던가 음
아진짜 없을까 아이디어가 다 이상한데 여기가 유저가 처음 보는 화면이라서 뭔가 확 와야 하는데 아 진짜 뭐 없나
3번이 좋은데 배경색 떄문에 또 어색할거 같은데
출발 안내판 C안 사진에 걸치기로 가자

## 순서
- 지금 진행 중인 글꼴(Pretendard 800) 작업을 먼저 끝내고, 그 브랜치 위에서 새 작업 폴더로 시작. PR 따로 하나, 커밋은 단계별.

## 무엇을
홈 맨 위 "오늘 환율" 울트라마린 띠(today-band)를 없애고 공항 출발 안내판(스플릿 플랩)으로 바꾼다.
1. **배경**: 울트라마린 전체 띠 제거. 사이트 바탕(하늘 종이 #EAF4F2) 그대로.
2. **사진에 걸치기**: 안내판 위쪽 절반이 위 히어로 사진(비행기 창 · 피오르)에 겹쳐 올라간다. 사진 아래 끝은 하늘 종이색으로 부드럽게 사라지게.
3. **안내판**: 울트라마린 #2438A8 판 · 칸 #3247b8 · 칸 가운데 이음선 · 도착지 줄은 흰 글자, 금액 줄은 햇빛 노랑 #F7C548. 판에만 울트라마린을 쓴다.
   - 1줄: 출발 → 도착지 (예: ICN → 도쿄). 2줄: 금액 (예: 833원 / 100엔). 한글이 칸에 맞게 고정폭 처리.
   - 위에 작은 제목 "이번 주 가장 싸게 갈 수 있는 곳", 아래 판정 한 줄(지금 환전하기 좋음 등, 지금 있는 판정 문구 그대로).
4. **움직임**: 처음 들어올 때 한 번만 글자판이 넘어가며 맞춰짐 (약 1~2초). prefers-reduced-motion 이면 바로 최종 글자. 다시 돌지 않음.
5. **접근성**: 안내판 전체에 읽을 수 있는 문장(aria-label 또는 숨김 텍스트) — 화면 읽기 도구가 글자 하나씩 읽지 않게.
6. **데이터**: 지금 today-band 가 쓰는 값 그대로. 값이 없으면 칸을 "----" 같은 빈 칸으로, 지어내지 않음.
7. **지구 위치**: 3D 지구 모양 · 비행기는 그대로. 데스크톱은 안내판 오른쪽에 (배경 띠 없이 하늘 종이 위), 모바일은 안내판 아래 작게. 지구 뒤 파란 원판 · 띠 없음.
8. 글꼴은 직전 작업의 Pretendard 800 기준. 제목 속 숫자 강조 규칙 유지.

## 확인
- 모바일 375 · 데스크톱 1440 · 1920 에서 사진 · 안내판 겹침이 깨지지 않는지, 금액이 긴 통화(예: 1,234.56원)도 칸이 넘치지 않는지.
- e2e: 안내판 도착지 · 금액 · 판정 한 줄 보임, 울트라마린 전체 띠 없음, reduced-motion 에서 최종 글자 바로 보임.
