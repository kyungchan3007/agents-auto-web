## 맡길 일: Search Console 사이트맵 "가져올 수 없음" 원인 조사 (#157)
- 현상: Search Console에서 sitemap.xml 상태가 계속 "가져올 수 없음"이고, 발견된 페이지가 0개입니다. 색인된 페이지는 홈 1개뿐입니다. sitemap.xml 에는 <loc> 29개가 들어 있습니다.
- 확인할 것:
  1. https://tripfx.pages.dev/sitemap.xml 응답 (상태 코드 · Content-Type · 리디렉션 여부 · 응답 크기)
  2. Googlebot 사용자 에이전트로 요청했을 때도 같은 응답이 오는지 (헤더에 Tripfx-Verify 를 붙여 통계에서 빠지게 할 것)
  3. robots.txt 의 Sitemap 줄이 정확한 주소를 가리키는지
  4. sitemap.xml 형식: XML 선언 · 네임스페이스 · <loc> 주소가 모두 https://tripfx.pages.dev 로 시작하는지, 실제로 열리는 주소인지 (29개 전부 상태 코드 확인)
  5. apps/web/public/_headers · _routes.json · apps/web/src/app/sitemap.ts 에서 응답에 영향을 주는 설정
- 원인 후보마다 근거(명령 · 응답 · 파일:줄)를 남길 것. 확인하지 못한 것은 "확인 못 함"으로 적고 추측해서 채우지 말 것.
