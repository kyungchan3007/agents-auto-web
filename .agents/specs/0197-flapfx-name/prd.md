# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 작업 0190(#217)에서 사이트 이름을 한글 "플랩"으로 넣었다. 사용자는 이름을 "Flapfx"로 쓰기를 원한다 (#228).
- 0196(#226)의 측정 질문 3판 브랜드 질문도 "플랩 flapfx …" 이다. 3판은 2026-11-18 측정부터라 그 전에 고쳐야 한 판 안에서 이름이 섞이지 않는다.

## 목표
- 사이트 이름 표기를 Flapfx 로: `SITE_NAME` · 페이지 제목 · 홈 제목 · 인트로 말풍선("안녕하세요, Flapfx 입니다!" 등) · 로딩 화면 · 공유 미리보기(opengraph) · 404 · 앱 설명서(manifest) 이름 · 아이콘 title · 메뉴.
- 문서(README · docs/*)의 사이트 이름 "플랩"도 Flapfx 로.
- 측정 질문 3판 브랜드 질문 "플랩 flapfx …" → "Flapfx …" (번호 b14~b21 그대로 · 아직 측정 전이라 판은 3판 유지). docs/geo-measurement.md · /geo 판 설명 글도 맞춤.

## 비목표
- "스플릿 플랩"(글자판 이름)은 사이트 이름이 아니므로 그대로 (`packages/ui/src/lib/flap.ts` · `flap-board.tsx` 주석 등).
- 지난 기록(작업 기록 · 지난 spec · 지난 측정 결과 파일)은 고치지 않는다.
- 보호 파일 `apps/web/wrangler.jsonc` 의 주석 한 줄은 승인 없이 바꾸지 않는다.
- 아이콘 그림은 0195 (#222) 에서.

## 애매한 곳
- 로고 글자: 지금 소문자 `flapfx` 그대로 둔다 (가정 · 이슈가 "이 이슈에서 정함"이라 했으나 로고는 워드마크라 소문자가 시안과 같음 · PR 에 적어 사용자 확인).
- 한국어 조사: "Flapfx 입니다" 처럼 띄어 쓰거나 "Flapfx입니다" — 받침 없는 발음(플랩에프엑스)이라 "Flapfx입니다 / Flapfx는" 으로 (가정).
