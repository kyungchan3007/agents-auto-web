## 항목 — 탑승권 상자 자동으로 사라짐
- 어디: `apps/web/src/features/home/components/ticket.tsx` 의 `aside[aria-label="탑승권"]`(`passOpen` 일 때 그리는 상자) · 여닫는 상태는 `usePickedDestination` 의 `passOpen` · `togglePass`
- 지금: "ICN → 뉴욕 탑승권 보기"를 누르면 상자가 움직임 없이 뜨고, 다시 누를 때까지 계속 떠 있습니다.
- 고치면:
  - 누르면 상자가 아래에서 10px 올라오며 나타납니다(불투명도 0 → 1 · 약 220ms · ease-out).
  - 뜬 뒤 **3초**가 지나면 아래로 10px 내려가며 **0.5초**에 걸쳐 흐려져 사라집니다(ease-in). 사라진 뒤에는 닫힌 상태(`aria-expanded="false"`)입니다.
  - 상자 위에 마우스를 올리거나 손가락을 대고 있는 동안에는 사라지지 않고, 떼면 3초를 처음부터 다시 셉니다.
  - 떠 있는 동안 링크를 다시 누르면 바로 닫힙니다(지금과 같음). 사라진 뒤 다시 누르면 다시 뜹니다.
  - 여행지를 바꾸면(다른 도시 칩) 떠 있던 상자의 내용이 바뀌고 3초를 다시 셉니다.
  - 움직임 줄이기를 켠 사람에게는 오르내리는 움직임 없이 흐려지기만 합니다. 3초 뒤 사라지는 것은 같습니다.
