# PRD: 반응형 전수 점검 · 여백 · 정렬

## 목표
- 어떤 폭에서도 눈에 띄는 빈 공간 · 쏠림이 없다. 오늘 새벽까지 develop 머지.

## 요구 (사용자 원칙)
- R1 나란한 두 칸은 아래 끝 차이 24px 이하 또는 짧은 쪽이 내용으로 참(빈 띠 없음).
- R2 899px 이하 한 줄 배치에서 모든 덩어리가 같은 가운데 기둥(좌우 여백 ±2px).
- R3 입력 · 클릭 · 응답 · 모션 · 글꼴 로딩으로 높이 · 위치가 움직이지 않음.
- R4 장식을 새로 더하지 않음(여백은 배치로).
- 알려진 문제: ① /prices/[code] 환율 있는 나라 1024+ 왼쪽이 145px 김(환율 없는 나라는 반대일 수 있음) ② 첫 페이지 블프 장 600~899 글 칸 쏠림 + 영수증 아래 큰 빈 공간(두 장 중 긴 장에 높이를 맞춘 탓) ③ 전수 점검으로 나오는 것 모두.
- 첫 페이지 아래 구역(section.today 도착지별 환전 타이밍)이 화면에 들어올 때 435 → 984px 늘어나는 것(0395 에서 찾음 · R3)도 이번에 포함.
