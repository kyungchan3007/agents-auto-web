# 계획

## 무엇을 · 왜
- AI 답변 인용 측정(geo-ask)의 실행 결과와 저장 여부를 측정 페이지(/geo)에서 모두 볼 수 있게 한다 (사용자 요청)
- 지금은 서비스별 요약 한 줄과 인용된 질문만 보여 주고, 키가 없는 서비스 · 질문별 결과 · 날짜별 저장 기록은 보이지 않는다

## 애매한 곳
- "실행 결과" = 최근 측정일의 질문별 결과(답에 인용 · 검색 결과에 나옴 · 성공/실패) (가정)
- "저장 확인" = 날짜 · 서비스별로 D1 에 저장된 질문 수 · 응답 받은 수 · 인용 수 (가정)
- 키가 없어 측정하지 않은 서비스는 "측정 안 함 (키 없음)"으로 표시 (가정 · 저장된 행이 없는 서비스)
- 질문별 표는 서비스마다 접어 두는 칸(details)으로 (가정 · 24줄 × 3)
