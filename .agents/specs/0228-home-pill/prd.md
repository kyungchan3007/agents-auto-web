# PRD — 무엇을 · 왜

> 요청 원문: [request.md](request.md) "### 1. 홈 도착지별 환전 타이밍"

## 문제
- 홈 "도착지별 환전 타이밍" 카드는 지금 움직임 없이 바로 나온다. 사용자가 고른 모션 13번(요약 알약 펼치기)을 더해야 한다.
- 펼칠 때 금액이 "최근 90일 중간값 → 오늘 값"으로 카운트업되는데, 홈이 받는 신호 목록(/signal)에는 중간값이 없다. 숫자를 지어낼 수 없으므로 API 가 실어 줘야 한다.

## 목표
- 카드가 화면 아래에 있으면 알약(국기들 + "도착지 N곳 중 M곳이 최근 90일 중 싼 편")으로 접어 두고, 윗부분이 들어오자마자 약 1초 안에 펼친다(높이 약 0.46초 · 모서리 → 24px · 줄 0.07초 간격 · 점 가운데 선 → 오늘 0.62초 · 금액 중간값 → 오늘 같은 시간 · 신호 글 마지막).
- M 은 사이트 신호 규칙(하위 30% 이하 = cheap)으로 센다.
- 신호 목록 줄에 `median`(최근 90일 창의 중간값 · `latest.value` 와 같은 1 외화당 원 단위, 선택 값)을 더한다. 추가 D1 읽기 없음 — 신호 계산이 이미 읽은 같은 줄로 계산.
- 끝 상태는 지금 운영 카드와 똑같다. 빼는 것 없음.

## 비목표
- "이 구역 움직임 다시 보기" 버튼(시안 미리보기 전용, 운영에 없음)은 만들지 않는다.
- 2번 안내판 순환 · 8~12번 시안은 쓰지 않는다.

## 애매한 곳
- 중간값이 없는 줄(자료 부족 · API 배포 전) → 카운트업 없이 오늘 값 그대로 (가정 · 숫자 지어내지 않음). 미리보기는 API 가 머지 뒤 배포되므로 그때까지 카운트업 없이 나온다.
- 첫 화면에서 이미 카드가 보이면 알약에 0.4초 넘게 머물지 않고 바로 펼침 (가정 · 시안 동작)
- 움직임 줄이기 · JS 꺼짐이면 알약 없이 최종 카드 (확인됨: 브리프)
