## 무엇을
`docs/design-tests-pending.md` 에 쌓인 8개(0248 의 6개 + PR #299 에 적은 0249 의 2개)를 지금 모양에 맞게 정리한다.
- 원칙(정한 규칙 6번): 전부 되살리지 않는다. **크게 깨지는 것만 잡도록 줄인다** — 요소 겹침 · 화면 밖으로 나감 · 주요 구역이 안 보임은 남기고, 여백 · 좌표 · 색 · 모서리의 정확한 값을 고정하는 검사는 없애거나 느슨하게.
- 항목별
  - `prices-title.test.ts` 예산 카드 위치(단위) · `prices-redesign.spec.ts` 예산 카드 위치(e2e): 정확한 값 고정을 걷어 낸다. "카드가 파랑/흰 경계에 걸친다 · 제목과 겹치지 않는다" 정도만.
  - `redesign-foundation.test.ts` 공용 부품 그림자 없음: **팝업(pick-trip.tsx)과 국기 테두리(flag.tsx)는 예외**로 두고 검사는 유지(사용자 결정: "팝업 그림자는 사용해야지 안그러면 구분이 안되니까"). 예외는 파일 이름으로 명시하고 이유를 주석 한 줄로.
  - `prices-redesign.spec.ts` 나라 더 보기: 사용자가 바꾼 새 조건(편 상태는 한 목록 · 접기는 목록 끝 왼쪽)에 맞춘다. "접기 버튼이 보이고 눌린다"는 남긴다.
  - `prices-route.spec.ts` 예산 카드 아래 → 노선 제목 간격 140px: 값 고정을 걷어 내고 "겹치지 않는다 · 간격이 0 보다 크다" 정도만.
  - `detail-design.spec.ts` 통화 목록 알약: 17번에서 배지를 조용한 글자로 바꿨으므로 새 모양(판정 글자가 '환율' 로 시작하지 않음)으로 고치거나 없앤다.
  - `number-emphasis.test.ts` 형광펜 띠 높이(24번): 새 값(64~90%)에 맞추거나 "띠가 글자 폭 안에 있다"로 느슨하게.
  - `calc-gap.spec.ts` 물건 값 안내 아래 간격(2번 영향): 넓은 화면에서 입력 카드를 늘리며 달라진 것. 값 고정을 걷어 내고 "오류가 떠도 입력 칸 높이가 그대로"(기능 조건)는 남긴다.
- 고친 뒤 `docs/design-tests-pending.md` 의 "쌓인 목록"을 비운다(형식 설명은 남김). PR #299 는 이 작업에 합치거나 닫는다(lead 판단).
- e2e 는 넓은 화면과 휴대폰 둘 다 맞는지 본다 — develop 대상 CI 는 넓은 화면만 돌고, 휴대폰은 메인으로 보내는 PR 에서 처음 돈다. 고친 e2e 는 로컬에서 휴대폰 프로젝트로도 한 번 돌린다.
