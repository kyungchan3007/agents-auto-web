# PRD — 무엇을 · 왜

> 요청 원문: [request.md](request.md)

## 문제
- 어드민(admin.flapfx.com)의 작업실 · GEO 측정이 방문자 사이트의 큰 제목 · 파란 머리띠를 그대로 써서 운영 화면답지 않고, 매일 볼 상태 · 요약 숫자가 아래에 묻혀 있다.
- 리뷰어가 이 사이트를 만드는 방식(사람 · 에이전트 팀 · OpenRig · Herdr · 규칙)을 한곳에서 이해할 화면이 없다.

## 목표
- 시안(Version 6)대로 어드민 세 화면: 작업실 · GEO 측정 · 만드는 방식(/how). 내용은 지우지 않고 자리만 옮긴다.
- 프론트엔드 조작(찾기 창 · 초성 · 단축키 · 걸러 보기 · 정렬 · 다시 받기 · 링크 복사)과 모션(안내판 숫자 · 막대 · 판 올라옴)을 넣되 움직임 줄이기 · 키보드 · 화면 읽기를 지킨다.

## 요구사항
| ID | 요구 | 확인 |
| --- | --- | --- |
| ADD-01 | 어드민 세 화면은 왼쪽 메뉴(작업실 · GEO 측정 · 만드는 방식 · 사이트로 가기) · 휴대폰은 위쪽 탭 | e2e |
| ADD-02 | 찾기 창: ⌘K / Ctrl+K 로 열고, 화면 · 판 · 질문 · 규칙을 찾고(한글 초성 포함), 화살표 · Enter · Esc | 단위(찾기 함수) · e2e |
| ADD-03 | 단축키 1 · 2 · 3 화면 이동 · / 질문 걸러 보기 · 입력 중에는 동작 안 함 | e2e |
| ADD-04 | 작업실: 상태 숫자 칸(다시 받기 · 5분 남은 시간) → 실시간 기록 · 팀(data 포함 다섯) 같은 높이 → 작업 흐름 한 줄 → 이 사이트를 어떻게 만들었나 | 단위 · e2e |
| ADD-05 | GEO: 요약 숫자 4 → 날마다 측정 그래프(막대를 누르거나 포커스하면 그날 기록) · 봇 방문 → 이름 바꾼 날 전후 → 일반 질문 표(걸러 보기 · 정렬) · 검색 노출 · AI 봇이 읽은 페이지 · 유입 → 봇별 읽은 페이지(전체 · AI 봇 · 검색 엔진) → 측정 방법 · 한계 · 기존 내용 모두 유지 | e2e |
| ADD-06 | 만드는 방식: 소개 · 흐름 그림(자리 누르면 설명 · 따라가기) · 도구 3 · Herdr 모습 · 규칙 12(묶음 · 펼치기 · 원본 링크) · 궁금한 것 10(골라 보기) | e2e |
| ADD-07 | 사람 역할 문구: 기획과 설계 · 디자인 방향과 레퍼런스를 사람이 정함 · 모델을 나눈 이유 질문 | 단위 |
| ADD-08 | 움직임 줄이기를 켜면 모션 없이 최종 값 · 숫자는 화면 읽기에 최종 값 | e2e |
| ADD-09 | /how 도 어드민 주소로 넘김 · 검색 막음 | worker 단위 |
