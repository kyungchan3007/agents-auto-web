# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- AI 봇이 사이트를 얼마나 읽는지, AI 서비스에서 얼마나 넘어오는지 볼 방법이 없음
- 지금 시작하지 않으면 3~4주 뒤 비교할 기록이 없음

## 목표 (1단계)
- 공개 페이지 `/geo`: AI 봇 방문 · 검색 엔진 방문 · AI 서비스 유입 · 인용 측정 기록
- 수치마다 추정치 · 표본이라는 한계를 함께 표시

## 비목표
- Search Console · Bing 자료 연동 (2단계 · 인증 정보 필요)
- AI 답변 인용 자동 측정 · 사람 방문 집계

## 불변식
- 방문자 IP · 전체 User-Agent · 전체 유입 주소 · 쿼리를 저장하지 않음
- 집계가 실패해도 페이지는 그대로 열림
- 사람 방문은 저장하지 않음 (AI 서비스 유입은 서비스 이름과 페이지만)
- 받지 못한 숫자는 지어내지 않음

## 완료 기준
- [ ] 집계 · 분류 · 응답 테스트 · 게이트 Full
- [ ] 운영에서 시험 방문이 집계되고 공개 수치에 섞이지 않음
