# PRD — 무엇을 · 왜 (디자인 변경 전체 + 이 작업의 범위)

> 요청 원문: [request.md](request.md) · 기준 디자인: [design-plan.md](design-plan.md) · Figma https://www.figma.com/design/ssKUqcVolukUjz3paXjxg2 (화면별 설명 정리: `figma-spec.md`)

## 문제
- 지금 사이트는 검정 바탕 · 회색 글자 · 오로라 포인트라 "ERP 디자인 같다"는 평을 받았다 (사용자). 사이트를 처음 보는 사람이 무엇을 하는 곳인지 바로 알 수 있어야 한다.
- 사용자와 테마 C "항공 노선도" · 빈티지 항공 포스터 색으로 합의했다 (2026-11-15).

## 목표 (디자인 변경 전체 — 작업 3개로 나눔)
1. **0168 공통 기반 (이 작업)**: 새 색 토큰 · 글꼴 · 메뉴 순서 · 공통 컴포넌트 모양 · 밤 포스터(어두운 화면 모드) · 3D 색 고정 · 고양이 · 동전 제거 — 모든 화면이 새 테마로 보이게 하는 바닥
2. **0169 홈**: 여행 타이밍(맨 위 선 그래프 + 선을 따라 나는 3D 비행기) → 울트라마린 띠(3D 지구 + 이번 주 가장 싼 도착지) → 도착지별 환전 타이밍(판정 핀)
3. **0170 나머지 화면**: 통화 · 여행 물가 · 여행 타이밍(/flights) · 직구 계산(노란 도장) · 작업실 · GEO · 소개 · 디자인

## 이 작업(0168)의 요구사항
- R1 색: 하늘 종이 #EAF4F2(바탕) · 울트라마린 #2438A8(쌈 · 바다 띠 · 큰 제목) · 해 노랑 #F7C548(가장 좋은 때 강조) · 바다 청록 #17A398(작은 제목 · 바닥 띠) · 양귀비 주홍 #D9452B(비쌈) · 글자 #16246E / 보조 #4A5A8C
- R2 판정 색은 쌈 = 울트라마린 · 비쌈 = 주홍 (한국 관례 파랑 · 빨강) 둘뿐. 해 노랑은 "가장 좋은 때"에만
- R3 글꼴: 큰 제목 · 큰 숫자 Gasoek One · 본문 IBM Plex Sans KR (400 · 600) · 숫자 tabular-nums. `next.config` 를 건드리지 않는 방식 (layout.tsx 의 next/font)
- R4 메뉴 순서: 여행 타이밍 · 오늘 환율 · 통화 · 여행 물가 · 직구 계산 · 작업실 · GEO 측정
- R5 어두운 화면 모드 = "밤 포스터"(울트라마린 바탕) — `prefers-color-scheme: dark` 에서
- R6 대비: contrast.test.ts 기준 (본문 4.5 · 큰 글자 3) — 밝은 화면 · 밤 포스터 · 바다 띠 모두
- R7 3D 지구 · 비행기 생김새 그대로: 3D 가 읽는 색은 지금 값으로 고정 (3D 전용 토큰)
- R8 고양이(cat-figure · money-cat · worker-cat) · 동전(coin)을 화면에서 뺀다
- R9 표 줄 · 테두리 상자 · 똑같은 둥근 카드 반복 · 장식 그라데이션 · 그림자 · 등장 효과를 공통 컴포넌트에서 걷어 낸다 (움직임은 3D 뿐)
- R10 `docs/design.md` 결정 요약을 새 결정으로 갱신

## 하지 않는 것 (이 작업)
- 각 화면 배치 바꾸기 (0169 · 0170) — 단 공통 컴포넌트가 바뀌어 화면이 새 색 · 글꼴로 보이는 것은 이 작업의 결과
- 보호 파일 변경 (next.config · wrangler · package-lock 등)
- 숫자 · 자료 처리 변경

## 성공 기준
- 모든 페이지가 새 색 · 글꼴로 보이고, 고양이 · 동전이 어느 화면에도 없다
- 지구 · 비행기는 바꾸기 전과 같은 색으로 보인다 (미리보기 캡처 비교)
- 밝은 화면 · 밤 포스터 모두 대비 기준 통과 · `checks.sh` (Full: build · e2e 포함) PASS
