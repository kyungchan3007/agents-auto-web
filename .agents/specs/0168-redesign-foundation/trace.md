## 허점
- lead 가 builder 가 작업 중인 worktree 에서 `git commit -am` 을 실행해 builder 의 변경을 자기 커밋으로 묶어 push 함 → 즉시 되돌림(reset --soft · force-with-lease). 남이 쓰는 worktree 에서는 경로를 지정해 커밋한다 (`git commit -- 경로`).
- 셸 위치가 앞 명령의 cd 를 따르지 않아, 0171 에서 돌리려던 게이트가 0168(작업 중)에서 Full 로 돌았음 (빌드 한 번 D1 읽기). 게이트는 `cd <worktree 절대 경로> &&` 와 같은 명령 안에서 돌린다.
