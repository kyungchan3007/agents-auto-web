> ## 정한 방법 (claude-desktop 이 사용자에게 설명한 안 1)
>
> - **사용자에게는 표가 보이지 않는다.** 통화 상세(`/currencies/[code]`) 맨 아래 "둘러보기" 표 구간을 화면에서 뺀다. 페이지는 자주 묻는 질문에서 끝나고 그 아래 출처 줄.
> - **링크는 HTML 에 남긴다. 단 "끝까지 숨긴 표"로 남기지 않는다.** 검색엔진은 사용자에게 절대 보이지 않는 글을 낮게 친다. 대신 "다른 나라 통화 보기" 사이드바(작업 0356 · 0361 공통 부품)의 통화 목록을 **서버 첫 그림 HTML 에 미리 그려 두고**, 버튼을 누르면 보이게 한다(눌러서 보이는 글 = 보이는 글과 같게 취급). 지금 사이드바 목록이 누를 때 그려지는 방식이면 이 부분을 바꾼다. 22개 통화 링크(`/currencies/XXX`)가 HTML 에 그대로 있는지 확인.
> - 화면 읽기 프로그램에서 목록이 두 번 읽히지 않게(닫힌 사이드바는 접근성 트리에서 빠지도록).
> - 자바스크립트가 없을 때 "다른 나라 통화 보기" 버튼은 지금 "둘러보기" 표로 내려가는 링크 → `/currencies` 통화 목록 페이지로 바꾼다.
> - 다른 화면에서 이 표 구간(rate-table · 90일 최고보다)을 쓰는 곳이 있으면 그대로 둔다. 통화 상세에서만 뺀다.
