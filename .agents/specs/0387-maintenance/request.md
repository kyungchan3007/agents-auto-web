> ## 만들 것
> 1. 사이트 코드 · 빌드와 따로 서는 점검 화면 묶음 (예: `apps/web/maintenance/` — 위치는 sdd 에서)
>    - HTML 한 장(시안 그대로) + 아주 작은 Worker: 모든 주소 요청에 이 HTML 을 503 + `Retry-After: 3600` + `Cache-Control: no-store` 로 돌려줌. `/robots.txt` 도 503(검색엔진이 사이트를 지우지 않게).
>    - Next 빌드 · 데이터 · D1 · API 에 기대지 않음 → 사이트가 어떻게 깨져도 이것만은 뜸.
> 2. 켜기: 명령 하나로 운영 Worker(agents-auto-web · flapfx.com · www)에 이 점검 버전을 바로 배포. 예: `npm run maintenance:on`.
>    - 가능하면 GitHub Actions 수동 실행(workflow_dispatch "점검 화면 켜기")도 — 사용자가 휴대폰에서 눌러 켤 수 있게. 필요한 Cloudflare 토큰 · 권한이 없으면 사람에게 받을 것을 PR 에 적기 (비밀값은 코드 · 로그에 쓰지 않음).
> 3. 끄기: 바로 전 정상 버전으로 되돌리기(`wrangler rollback` 또는 대시보드 Deployments → 이전 버전). 명령 `npm run maintenance:off` 와 수동 실행도 같이.
>    - 켤 때 그 직전 버전 ID 를 출력해 두어 되돌릴 곳을 헷갈리지 않게.
> 4. 사용 방법을 짧게 문서로 (docs/ 운영 문서 한 곳): 언제 켜는지 · 켜기 · 끄기 · 확인 방법.
