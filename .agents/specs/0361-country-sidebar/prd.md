# PRD: 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 여행 물가 싼 곳 · 비슷한 곳 · 비싼 곳 목록에서 나라를 누르면 나라 페이지로 넘어가 흐름이 끊긴다(사용자 "이거 불편해").

## 목표
- 목록 나라를 누르면 사이드바(1024px 이상) · 바텀 시트(1024px 미만)로 연다. HTML 의 /prices/[code] 링크는 그대로, 누를 때만 가로챔.
- 넓은 화면: 오른쪽 420px · 뒤를 덮지 않고 본문을 왼쪽으로 밀어냄(목록 세 칸 모두 보이고 누를 수 있음 · 좁아지면 한 줄로 쌓임) · 뒤 스크롤 잠그지 않음.
- 좁은 화면: 아래 78% 시트 · 뒤 어둡게 · 스크롤 잠금 · 바깥 누르면 닫힘.
- 연 채로 다른 나라 · ‹ › 앞뒤: 내용만 옆으로 · "n / 전체".
- 내용: 경로 · 물가 문장 · 오늘 통화 한 줄 답(없으면 물가만) · 물가 값 · 하루 예산 예시 · 다음으로 볼 것 셋 · 맨 아래 나라 페이지 링크.
- 모션 A(누른 줄이 늘어나 사이드바 · 닫으면 그 줄로) · 움직임 줄이기 바로 · dialog · 포커스 · Esc.
- 사이드바 · 시트 · 모션 · 스크롤 잠금은 통화 상세(0356)의 것을 공통 부품으로 꺼내 두 화면이 같이 씀.
- 0360 노선 카드 "{나라} 자세히 보기 ›"도 이 사이드바를 엶.

## 비목표
- 나라 페이지(/prices/[code]) 자체 변경.

## 애매한 곳
- 넓은 화면 밀어내기 방식: 본문 컨테이너 오른쪽 여백 420px (가정 · 시안 그대로).
- 작업 종류 ③: 요구마다 기능 테스트 · 움직임 모양은 @design · 세 폭 1440 · 900 · 375.
