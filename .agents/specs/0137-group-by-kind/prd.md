# PRD — 무엇을 · 왜

> 원문(request.md)을 옮긴 파생 문서. 요구 충족 판정 기준은 언제나 원문이다

## 문제
- 기능 폴더와 패키지의 가장 아래 폴더에 화면 · 훅 · 계산 · 테스트가 섞여 있어 찾기 어렵습니다. (통화 기능 30개, 컴포넌트 28개가 한 폴더에 있었습니다.)

## 목표
- 파일을 성격별 폴더로 묶습니다.
- 다시 흐트러지지 않게 테스트로 막습니다.
- 동작과 화면은 바꾸지 않습니다.

## 비목표
- 파일 내용 변경 (import 경로 제외) · 파일 합치기

## 애매한 곳
- 원문의 "파일 만들어서" 는 폴더를 만들어 묶는 뜻으로 봅니다 (가정).
- 파일이 적은 API 슬라이스와 `apps/web/src/shared` 는 나눠도 찾기 쉬워지지 않아 그대로 둡니다 (가정).
