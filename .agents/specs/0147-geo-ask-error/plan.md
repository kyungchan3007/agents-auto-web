# 계획

## 무엇을 · 왜
- geo-ask 실패 로그에 상태 코드만 남아 HTTP 400 의 원인(요청 형식 · 크레딧 · 모델 등)을 알 수 없다. API 오류 종류와 메시지 앞부분을 함께 남긴다. 키 · 답변 본문은 계속 남기지 않는다.
- 처음 3개 질문이 요청 오류(400 · 401 · 403 · 404)로 연달아 실패하면 나머지는 묻지 않고 실패로 기록한다. 고칠 때까지 매일 같은 실패를 24번 반복할 필요가 없다.
