# PRD — 무엇을 · 왜 (0173 글꼴 정리)

> 요청 원문: [request.md](request.md) · 디자인 기준: [0168 prd](../0168-redesign-foundation/prd.md) · [0170 sdd](../0170-redesign-pages/sdd.md)

## 문제
- 사용자: "폰트가 두껍다고 해야 하나… 가독성이 좀 떨어지는 것 같아". 지금은 큰 제목뿐 아니라 구간 제목 · 도시 이름 · 카드 제목 · 단계 제목까지 포스터 글씨(Gasoek One)라 화면 전체가 무겁다.
- 사용자가 비교안 중 A 를 골랐다: 맨 위 큰 제목 · 큰 숫자만 포스터 글씨, 나머지 제목 · 도시는 IBM Plex 굵게.

## 요구사항
- F1 Gasoek One 은 **화면 맨 위 큰 제목(페이지 제목)과 큰 숫자, 로고**에만.
  - 홈: 여행 타이밍 큰 문장 · 바다 띠의 "이번 주 가장 싸게 갈 수 있는 곳은 …" 문장 · 노란 큰 숫자 / 통화 상세 큰 환율 / 직구 큰 문장 · 결과 금액 / 각 화면 맨 위 제목 / 로고 tripfx
- F2 그 밖의 제목은 **IBM Plex Sans KR 굵게(700 · 필요하면 600)**: 구간 제목(도착지별 환전 타이밍 · 실제로 바꿀 때 · 이번 주 과세환율 · 수입물가와 환율 · 여행 하루 예산 · 사이트 상태 · 팀 책상 · 작업 흐름 · 이 사이트를 어떻게 만들었나 · 단계 제목 등) · 도시 이름(도착지 줄 · 여행 물가) · 카드 제목 · 팀 책상 역할 이름 · 작은 제목 전부
- F3 토큰 · 공통 부품 단위로 바꿔 화면마다 따로 고치지 않는다 (font-display = 큰 제목 · 큰 숫자 전용, 구간 제목 · 도시 · 카드 제목은 공통 부품이 IBM Plex 굵게).
- F4 크기 · 배치 · 색은 바꾸지 않는다 (글꼴 · 굵기만).
- F5 docs/design.md 글꼴 결정 갱신.

## 추가 요청 — 밝은 화면 하나만 (12:14)
- L1 어두운 화면 모드("밤 포스터")를 없앤다. 기기 설정과 상관없이 항상 Figma 시안의 밝은 화면(하늘 종이 바탕).
  - `prefers-color-scheme: dark` 에 반응하는 토큰 · 스타일 · 3D 조명 분기 · 테마 색(themeColor) 분기 제거 · `color-scheme: light` 고정
  - 시안에 있는 어두운 구간(홈 바다 띠 · 직구 결과 카드 · 작업실 실시간 기록)은 그대로
- L2 밤 포스터 관련 테스트 · 문서(docs/design.md 결정)를 정리 — 결정 변경: 밝은 화면 하나
- L3 다크 모드 기기에서도 밝은 화면으로 보이는지 확인 · PR 에 다크 모드 기기 캡처

## 성공 기준
- 위 F1 목록 밖에서 Gasoek One 이 화면에 나오지 않는다 (소스 검사 + 캡처)
- 전 · 후 캡처를 PR 에 · `checks.sh` (Full) PASS
- 기기를 어두운 화면 모드로 둬도 화면이 밝은 화면과 같다 (캡처)
