# 계획

## 무엇을 · 왜
- 홈 "도착지별 환전 타이밍"은 대표 도착지 네 줄만 보여 주고 다른 통화로 가는 길이 없다 (#218).
- 목록 아래에 통화 전체(`/currencies`)로 가는 링크를 하나 둔다. 문구는 "다른 통화 N개 모두 보기 ›".
- N 은 빌드 때 받은 실제 통화 수에서 화면에 보이는 대표 통화 수를 뺀 값이다. 지어내지 않고, 통화 자료가 없으면 개수 없이 "통화 모두 보기 ›".

## 애매한 곳
- N 의 기준: /currencies 에 실제로 보이는 통화 수 − 위 목록에 이미 나온 통화 수 (가정 · 이슈 예시 22개는 데이터로 다시 계산).
- 링크 모양은 기존 `text-cheap` · `›` 링크와 같게 (확인됨: 이슈).
